# 極限陀螺競技場 · SPINFORGE X

依 `docs/企劃書.md` 建立的繁體中文 3D 陀螺對戰遊戲，目前版本 **v0.22.3**。91 顆使用實際產品參考圖與各自的輪廓近似模型，搭配原創立體競技盤、特效及四首背景／交戰配樂。本專案為非官方粉絲作品。

[線上遊玩](https://spinforge-x-arena-20261111.will-lin.chatgpt.site/)

## 開始遊玩

Windows 雙擊 **`啟動遊戲.cmd`**。需 Node.js 22.12 或更新版；首次執行會安裝依賴，瀏覽器於伺服器就緒後自動開啟。

```powershell
npm install
npm run dev
```

開啟 http://127.0.0.1:5178 ，保留終端機，按 `Ctrl+C` 關閉伺服器。也可用 `npm run build` 產出 `dist/`，透過任意靜態網站服務部署。不可直接以 `file://` 開啟原始 HTML。

## 已實作

- 單人對電腦（初／中／高三級），高級會參考最近 10 局玩家的排序習慣。
- 同機雙人，選隊時遮蔽交接，各自選擇三顆、調整先鋒／中堅／大將。
- 91 顆圖鑑：BX 34、UX 24、CX 33，附繁體中文名與英文名，支援中文／英文／型號搜尋。名稱來源及譯名狀態見 [中文名稱](docs/chinese-names.md)；目前1筆可確認臺灣代理用名，其餘完整名保守標為參考譯名。
- 91 顆均使用 Takara Tomy 指定原廠組合俯視原圖；原83顆保留245張參考，新增8顆另有35張原圖，總計280張。新增款各有獨立俯／斜視；部分斜視含套裝配件，輪廓只取獨立俯視圖。卡片、隊伍、MVP與戰鬥共用原廠配色參考。來源見 [多角度圖片說明](docs/model-references.md)，先前83張原圖仍保留追溯。
- 以逐顆照片輪廓、厚度與軸心族群建立質量／慣量／穩定／接觸／機動／抓軌／鎖定等遊戲特性，衍生六項能力值；23 顆原待核類型已補核，全部商品附官方標示日期與產品連結。
- 3on3 先搶 4 分：旋轉 1、越界 2、爆裂 2、極限 3；同時終結不加分、保持原位重打；三場後原順序循環。
- 選落點、傾角、蓄力最佳區；3、2、1倒數內先懸停、降下、小幅彈起與落盤光環，GO後才推進正式物理。暫停會凍結開場；減少動態效果時略過降下與光環。每場每人一次、持續兩秒的氣勢呼喊。
- 固定 120 Hz 的 2.5D 物理：碗面吸引、類型移動、碰撞與質量、防禦吸收、低打高 15%、相反旋向吸轉、齒軌衝刺。
- Three.js 三段模型：72點分層金屬戰刃、塑膠底框、棘輪環與凸齒、55碼軸心外形族群、透明與金屬材質。一體式組件在拆解與爆裂保持連接；戰鬥可切近鏡，圖鑑可上下／左右拖曳、看側面／底部與三段拆解。另有火花、軌跡、衝刺追蹤、鏡頭震動與出界光柱。
- 原創立體競技盤：白色塑膠碗面、藍色細齒軌、透明護牆、支柱螺絲、底殼肋與光條，三出口具斜坡及有深度的接盤，保持原有物理判定。
- 四首原創配樂涵蓋選單、交戰、賽末點及結算，切換交叉淡化、暫停續播、離開分頁立即淡出。上方「♫ 配樂」可調整音量；調至0只保留音效，「音效 關」則全部靜音，設定會保存。首次點選操作後才啟用聲音。
- 碰撞依強度分為輕擦、碰撞、重擊：金屬共振、低頻衝擊及短噪聲分層合成，依碰撞位置分左右聲道。交戰配樂降低底音量，撞擊時自動壓低再恢復，保留配樂音量偏好與全域靜音。
- 火花增加圓形亮芯、橙色短拖尾與接觸閃光；鏡頭短促衰減震動，輕擦不會蓋掉重擊。暫停會凍結特效與鏡頭，減少動態模式停用震動／閃光。火花、閃光及撞擊聲部都有固定上限。
- Web Audio 保留衝刺／發射／終結聲與轉速連動左右聲道，配樂與音效分流並經總混音限制器。
- 暫停與切換視窗自動暫停；1×、2×、4×速度。對戰隱藏側欄與頁尾、使用全寬加高畫面，預設雙陀螺近鏡，可切回全場或全螢幕；中文型號名牌搭配原廠照片。
- 繪圖在120Hz物理步長間插值，保留連續圈數與左右旋；鏡頭位置／注視點與傾斜皆用依時間計算的阻尼。物理快照及軌跡緩衝重用；HUD以100ms間隔更新，進度條改transform，減少每幀配置與版面重算。大畫布依240萬繪圖像素預算調整3D解析度；圖鑑小畫布與DOM文字保持清晰。物理及戰績結果不變。
- 終結演出：爆裂三段散開後落穩、一體式保持連接；越界拋向側盤、極限快速衝入前盤，搭配各自音效、軌跡與色彩。旋轉終結及平手也有獨立音效；2.3秒演出內依序揭曉終結、勝者、加分與比分預覽，再正式計分。
- 整局結算加入獎盃、勝隊三顆陀螺與勝負短曲，保留逐場、衝量、最大衝量、衝刺、剩餘轉速、MVP及同隊再戰。暫停會凍結終結動畫，靜音／暫停會取消演出短音效；減少動態時直接展示穩定終點。
- IndexedDB 保存單人與雙人分開戰績、連勝、每顆紀錄、類型對戰表、終結分布、最高 10 分及最近 20 局。
- 匯出／匯入 JSON（上限 2 MB，先驗證再寫入，錯誤不覆蓋原戰績）。最近賽事可按場重播；保留種子、發射與呼喊的固定 tick。

新增款可用「新增 8」篩選：雷霆女武神、雄鹿巨角、海怪蠕動、黃蜂堡壘、龍獸勇擊重力、暴風天馬、暴風巨神及迪卡狂怒。中文均標參考譯名；原先6款推定旋向已依各自原廠商品頁的R圖示確認，詳情可查看逐款來源與核對日期。資料見[擴充核對](docs/catalog-expansion-sources.md)、[圖片](docs/catalog-expansion-images.md)。

## 操作

| 時機 | 1P | 2P |
| --- | --- | --- |
| 發射落點 | A／S／D：內／中／外 | ←／↓／→：內／中／外 |
| 鎖定蓄力 | 空白鍵 | Enter |
| 對戰中氣勢呼喊 | 空白鍵 | Enter |
| 暫停／繼續 | Esc 或畫面按鈕 | 同左 |

亦可全程使用滑鼠或觸控按鈕；雙人發射操作固定1P左、2P右；手機直向亦維持左右分區。交戰呼喊分居左右，計時置中。傾角使用滑桿；雙人各有 ±1° 微調，手機發射頁操作區在盤面預覽前方，傾斜方向可選偏內切／沿旋向／偏外切，左右旋以各自旋向解讀。氣勢提高齒軌咬合能力，不直接補充轉速。

## 資料與版本限制

官方類型／日期的來源與一體式零件修正見 [圖鑑核對](docs/catalog-verification.md)。日期表示日本官方發售或預定日，並非到貨證明；BX-54、CX-20 的 2026-11-21 保留預定標示。

**六項數值均為遊戲平衡值，質量指數不是官方數據或公克實測。** 新版以 `src/combat-profiles.ts` 第1版規則，從保存的照片輪廓、分層尺寸與軸心結構推導個體差異，取代名稱雜湊；類型基值仍是可校準的遊戲設定。未逐顆重建真實陀螺的空氣力學、橡膠摩擦或真實幾何，結果不能用於實體產品性能比較。

**v0.2.0 平衡驗收通過**：4,096 場校準、16,384 場獨立種子驗收、3,984 場最低／最高蓄力與落點傾角邊界，共 24,464 場，全部 15.04–39.62 秒。獨立驗收的攻擊／防禦／持久／平衡整體勝率為 49.24%／46.35%／56.31%／47.97%。每類型面對等量各型對手，交換先後手，平手計入出戰分母。完整交叉對戰表見 [v0.2.0模擬報告](docs/balance-report-v020.json)。

時長以預設 1× 的模擬秒數計算，不包含降下、終結演出或暫停；衝刺命中慢動作會略增實際播放時間，加速播放會縮短等待時間。勝率描述四類型面對等量各型對手並交換玩家側的測試分布；自選隊伍、操作與難度會改變實際勝率。四種終結依場上狀態判定，不按類型抽籤決勝。

v0.4.0 的側面與厚度依83筆逐顆照片分級近似（71筆有斜視、12筆依同類結構），不再只依BX/UX/CX套用三種厚度；詳見 [外形資料](docs/model-profiles.md)。所有尺寸仍屬照片估算，尚非逐顆 CAD 還原或實物量測。零件配色依照片估色；未確認下段配色以參考色近似。54碼軸心中34碼已核對官方詳解，20碼仍為外形族群近似；未確認齒輪採12齒通用外觀。CX-09目前展示藍面，未加入紅／藍面切換。詳見 [幾何參考](docs/part-geometry-references.md)。原圖保留原樣；v0.20.0開始使用保存的輪廓比例及分層估值推導能力，碰撞包絡仍採圓形近似。

中階手機實機效能、長時間音訊聆聽與跨裝置同步未驗證。WebGL 2 為必要條件；需啟用瀏覽器硬體加速。戰績依瀏覽器與網址隔離，線上網站與本機網址間請用 JSON 備份轉移。

自由改裝、聯名與復刻陀螺、線上排行、多人連線及桌面封裝依企劃留待後續，未加入首版。

**v0.10.0 戰鬥特色與終結調整**：物理版本4讓四類型有不同的移動與衝撞特性；圖鑑詳情與遊戲規則都有說明。

| 類型 | 戰鬥特色 |
| --- | --- |
| 攻擊 | 外圈高速追擊、齒軌衝刺與強衝量，代價是耗轉與反作用力 |
| 防禦 | 守住中心、降低受擊擊退，受擊後可加強下一次反擊 |
| 持久 | 小圈低速巡航、較低耗轉與左右旋傳能，較怕強擊退 |
| 平衡 | 週期切換中心防守與外圈進攻，四種終結都有勝機 |

盤緣物理通道與3D護牆共用出口角度；降低不合理的陀螺高轉速出界門檻，通過出口後依動量滑出，避免被下一tick護牆拉回。擊退倍率與爆裂鎖扣損耗分別校準，反擊條件在雙方碰撞結算前讀取，避免玩家處理先後產生優勢。

前15秒維持最低3%轉速、40%原始鎖扣及盤緣保護，減少保護解除後雙方一起爆裂；碰撞與打擊回饋照常。30秒後雙方每秒額外耗轉0.11，仍依場上狀態決勝，維持15–40秒對決。沒有按類型抽籤決勝或用終結抽籤取代物理。

獨立驗收16,384場：停轉46.87%、爆裂20.41%、越界18.68%、極限14.04%，平手約1.46%。攻擊／防禦／持久／平衡勝率49.54%／52.38%／43.46%／51.70%。與校準、91款邊界、全91×91配對及新8款專項合計62,340場，全部15.00–32.13秒。`npm run balance` 同時檢查類型勝率、時長、停轉不超過50%、爆裂及越界各至少10%、極限至少5%、平手不超過5%。

v0.10.0當時91款能力值與既有戰績不改動；該版新對戰保存版本4，舊v1/v2/v3保留凍結引擎，依原規則重播。原14.433秒例外在v2、v3分別保留原14.433秒及18.8秒結果。歷史驗收見[v0.9.1](docs/balance-qa-v091.md)與[v0.9.1報告](docs/balance-report-v091.json)；本次見[平衡報告](docs/balance-report.json)與[完整驗收](docs/combat-qa-v0100.md)。

**v0.11.0 盤體細節**：整圈齒軌由99個方塊齒升為235個斜面倒角齒，補齊連續齒根、雙邊壓條與支撐肋。外框採實際凹槽剖面、上緣斜面與封閉端蓋，底座增加分層倒角；碗面以頂點色漸層、透明保護漆反光加強曲率。保留三個出界通道、原盤面高度與視野。盤體44個繪製物件、60,908個三角形；齒牙與重複零件採實例化。詳見[盤體驗收](docs/stadium-qa-v0110.md)。

**v0.12.0 極限衝刺演出**：實際齒段咬合時先短暫貼軌，再以傾斜與漸寬雙色拖尾加強加速感；接觸點有方向火花及局部亮芯。三個出口空隙只呈現加速，不偽造齒牙接觸。音效由齒鳴接上升風切，衝刺時短暫壓低配樂；暫停、靜音與終結會取消尚未結束的衝刺聲。波形在交戰前預熱，拖尾重用固定幾何，粒子與音訊有上限。減少動態模式省略貼軌偏移、衝刺附加傾斜、拖尾與閃光，保留少量接觸提示。物理引擎4及能力值沿用原版；詳見[衝刺驗收](docs/dash-qa-v0120.md)。

## 驗證與開發

```powershell
npm test             # 規則、確定性、完整賽事、備份安全與重播
npm run build        # TypeScript 嚴格檢查及正式打包
npm run test:e2e     # 本機已安裝 Google Chrome，完整 1P / 2P 與手機版
npm run balance:check # 同一完整模擬，報告寫入忽略的artifacts；CI使用此命令
npm run balance      # 66,708場（含三種內外切方向）：校準、獨立種子驗收、邊界及全部91×91配對
node --experimental-strip-types scripts/expansion-balance.ts # 新款4,368場專項
npm run catalog      # 從保存的企劃書重新匯入83筆原始組合
```

`npm run catalog` 只重建原始組合；官方核對留在 `scripts/catalog-overrides.json`，不會被覆蓋。新場次保存物理版本5及特性版本1；未帶版本的 v0.1.0 場次以凍結的 v1 引擎與舊數值重播，版本2、3、4各沿用凍結的對應引擎及原91筆能力表。戰績與備份不清除，可繼續匯入使用。
