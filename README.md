# 極限陀螺競技場 · SPINFORGE X

依 `docs/企劃書.md` 建立的繁體中文 3D 陀螺對戰遊戲，目前版本 **v0.2.0**。83 顆使用實際產品參考圖與各自的輪廓近似模型，搭配原創特效及合成音效。本專案為非官方粉絲作品。

## 開始遊玩

Windows 雙擊 **`啟動遊戲.cmd`**。需 Node.js 22.12 或更新版；首次執行會安裝依賴，瀏覽器於伺服器就緒後自動開啟。

```powershell
npm install
npm run dev
```

開啟 http://127.0.0.1:5178 ，保留終端機，按 `Ctrl+C` 關閉伺服器。也可用 `npm run build` 產出 `dist/`，透過任意靜態網站服務部署。不可直接以 `file://` 開啟原始 HTML。

## 已實作

- 單人對電腦（初／中／高三級），高級會參考最近 10 局玩家的排序習慣。
- 同機雙人，選隊時遮蔽交接，各自選擇三顆、調整先鋒／中堅／大將。
- 83 顆圖鑑：BX 32、UX 24、CX 27，篩選／搜尋／排序、3D 拖曳預覽、六項雷達圖、零件與相性資訊。
- 83 張不同產品原圖：56 張 BeyGear 戰刃俯視圖、27 張 Takara Tomy 原廠組合俯視圖。卡片、隊伍與 MVP 使用實物圖；立體戰刃以每顆 72 點輪廓、產品貼圖與個別配色呈現。來源見 [圖片說明](docs/product-images.md)。
- 三張零件表合成六項遊戲數值；23 顆原待核類型已補核，全部商品附官方標示日期與產品連結。
- 3on3 先搶 4 分：旋轉 1、越界 2、爆裂 2、極限 3；同時終結不加分、保持原位重打；三場後原順序循環。
- 選落點、傾角、蓄力最佳區，3、2、1 發射；每場每人一次、持續兩秒的氣勢呼喊。
- 固定 120 Hz 的 2.5D 物理：碗面吸引、類型移動、碰撞與質量、防禦吸收、低打高 15%、相反旋向吸轉、齒軌衝刺。
- Three.js 戰鬥盤、依實物參考的三段模型、火花、軌跡、衝刺追蹤、鏡頭震動、終結近景與零件分離、出界光柱。
- Web Audio 合成碰撞／衝刺／發射／終結聲、轉速連動左右聲道、簡單選單與戰鬥節奏及賽末點聲部；可靜音。
- 暫停與切換視窗自動暫停；1×、2×、4× 速度；桌機與手機響應式介面。
- 本局逐場、衝量、最大衝量、衝刺與剩餘轉速統計、MVP、同隊再戰。
- IndexedDB 保存單人與雙人分開戰績、連勝、每顆紀錄、類型對戰表、終結分布、最高 10 分及最近 20 局。
- 匯出／匯入 JSON（上限 2 MB，先驗證再寫入，錯誤不覆蓋原戰績）。最近賽事可按場重播；保留種子、發射與呼喊的固定 tick。

## 操作

| 時機 | 1P | 2P |
| --- | --- | --- |
| 發射落點 | A／S／D：內／中／外 | ←／↓／→：內／中／外 |
| 鎖定蓄力 | 空白鍵 | Enter |
| 對戰中氣勢呼喊 | 空白鍵 | Enter |
| 暫停／繼續 | Esc 或畫面按鈕 | 同左 |

亦可全程使用滑鼠或觸控按鈕；2P 的發射控制區上下排列。傾角使用滑桿。氣勢提高齒軌咬合能力，不直接補充轉速。

## 資料與版本限制

官方類型／日期的來源與一體式零件修正見 [圖鑑核對](docs/catalog-verification.md)。日期表示日本官方發售或預定日，並非到貨證明；BX-54、CX-20 的 2026-11-21 保留預定標示。

**六項數值均為遊戲平衡值，重量也是正規化遊戲質量，不是官方數據或公克實測。** 戰刃的初始差異以名稱的穩定雜湊配置，軸心依類型配置起始值；可在 `src/catalog.ts` 的零件表持續調整。未逐顆重建真實陀螺的空氣力學、橡膠摩擦或真實幾何，結果不能用於實體產品性能比較。

**v0.2.0 平衡驗收通過**：4,096 場校準、16,384 場獨立種子驗收、3,984 場最低／最高蓄力與落點傾角邊界，共 24,464 場，全部 15.04–39.62 秒。獨立驗收的攻擊／防禦／持久／平衡整體勝率為 49.24%／46.35%／56.31%／47.97%。每類型面對等量各型對手，交換先後手，平手計入出戰分母。完整交叉對戰表見 [模擬報告](docs/balance-report.json)。

時長以預設 1× 的模擬秒數計算；樣本覆蓋遊戲可發射的 65%–100% 蓄力、三落點及 0–30 度傾角。勝率描述這個測試分布；自選隊伍、操作與難度會改變實際勝率。程式沒有按類型抽籤決勝、硬塞勝率、15秒前鎖定勝負或40秒強制判勝。四種終結仍依狀態判定；本次驗收以旋轉終結為主，爆裂約 5.8%，出界與極限終結較少。

立體模型的側面與厚度依俯視圖片近似，尚非逐顆 CAD 還原。56 張戰刃資料庫圖片展示來源的標準配色，與指定棘輪／軸心的原廠配色可能不同；27 張官方圖則依各自原廠組合對應。圖片原檔保留原樣。

中階手機實機效能、長時間音訊聆聽與跨裝置同步未驗證。WebGL 2 為必要條件；需啟用瀏覽器硬體加速。戰績依瀏覽器與網址隔離，私人網站與本機網址間請用 JSON 備份轉移。

自由改裝、聯名與復刻陀螺、線上排行、多人連線及桌面封裝依企劃留待後續，未加入首版。

## 驗證與開發

```powershell
npm test             # 規則、確定性、完整賽事、備份安全與重播
npm run build        # TypeScript 嚴格檢查及正式打包
npm run test:e2e     # 本機已安裝 Google Chrome，完整 1P / 2P 與手機版
npm run balance      # 24,464 場校準／獨立驗收／邊界測試，含失敗斷言
npm run catalog      # 從保存的企劃書重新匯入83筆原始組合
```

`npm run catalog` 只重建原始組合；官方核對留在 `scripts/catalog-overrides.json`，不會被覆蓋。新場次保存物理版本；未帶版本的 v0.1.0 場次以凍結的 v1 引擎與舊數值重播。戰績與備份不清除，可繼續匯入使用。
