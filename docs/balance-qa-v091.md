# v0.9.1 平衡與時長驗收

日期：2026-11-12。圖鑑91款，新增8款保留；能力值不變，物理版本升為3。

## 原因與修正

原固定案例UX-15 Tyranno Roar對BX-31 Tyranno Beat，seed72101967，power .6767411596607417／.9601050117402338、lane1／0、angle15／8、呼喊tick720／840。v2於14.433333秒發生爆裂：前一tick的抗爆裂值45.34049，被單次碰撞扣至-2.46963。新規則下同輸入於18.8秒爆裂，勝方仍為玩家2。

為使15–40秒成為共通規則，v3前15秒保留最低0.03轉速、0.01鎖扣，盤緣不允許越界；碰撞後推擠也會重新限制於盤內。不是先產生結果再延遲播放，模型不會在已停轉或出盤後等待。15秒後解除保護，30秒後每方每秒額外耗轉0.11；沒有依類型抽籤、比較分數強制選勝方或移動時間戳。

上界：30秒時各方轉速至多1，總和至多2；後段每秒至少合計耗轉0.22，對向旋轉的傳能只交換能量。因此只要尚未有人終結，40秒前必有一方耗盡。新規則適用新場次；舊v1/v2場次依保存版本重播。
