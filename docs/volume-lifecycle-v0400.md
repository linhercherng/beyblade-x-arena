# v0.40.0 暫停、背景與音量設定

快速暫停後恢復，原本會等待舊曲180ms尾音結束，但共用配樂增益已開始升回新音量。暫停中把低音量調高時，這個升音也作用在退役曲目上。原碼回歸先重現100ms內舊曲未結束；校準原生增益後亦量到有效尾音從0.04551升到0.05177。

產品只修改Sound.update的一個呼叫：從null模式恢復至有效模式時，啟用既有setMusicGain的reopening保護。舊曲15ms收尾、20ms後才恢復共用增益；滑桿、靜音及換場繼續共用同一截止時間。原本的revision、ready、來源ended等待及配樂位置保存均保留。正常首次啟用沒有退役曲目，不新增延遲或聲源。

新增四項回歸：快速暫停／調高／恢復的尾音與實際輸出；背景期間調音量和靜音、系統自行恢復不得漏音；零配樂跨背景恢復仍可播放新語音；正式單人與雙人在暫停中改設定、背景恢復及繼續後仍保持靜音，取消靜音才恢復一份可聽配樂。重用audio-game原本的原生AudioContext量測helper，未新增產品測試介面。

修正前原生三項為1失敗、2通過；修正後連同既有音量控制和正式音訊流程共12項通過。尾音校準改為不反升；重新開聲同時檢查來源數、RMS、主增益及保存值。完整回歸、公開站與雲端結果另外收錄在發布驗收紀錄。

沿用原localStorage鍵、音量範圍與靜音清理。切回前景仍保持暫停和無聲，待使用者操作才恢復；配樂調至零仍保留新音效與語音。未改物理、能力值、亂數、引擎版本或戰績格式，保留v1～v5舊重播。

頁面背景事件及原生Chrome音訊圖驗證，不等於實體iPhone／Safari、鎖屏、耳機或來電驗收；目前沒有可測實機。
