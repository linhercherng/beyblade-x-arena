# v0.37.0 重播退出與跨場音訊

重播自然結束與跳過沿用同一清理路徑。stopCues在沒有目前聲部時保留既有15ms淡出；stopVoice在無播報且無優先退讓時直接返回，避免連續清理、勝負或倒數接續時硬切尚在淡出的上一段。新聲部仍會清理更舊尾音，維持原有主聲部加一個尾音上限。播放物件的取消旗標、來源身分與原生ended清理規則保持原樣。

tone的鎖定／呼喊等短音納入既有stopEffects清理，以15ms淡出。背景硬靜音同時斷開短音和曲目尾音的增益節點，不讓它們在恢復後繼續響起。

曲目尾音以musicTails追蹤。前次500ms交叉淡出尚未完成時，只保留最新切換請求，等原生ended後再檢查revision與ready；不增加第三首曲目。暫停把當前曲目及既有尾音一併在180ms內淡出，取消等候中的過期切換，恢復後不補播。正常切換沿用原本的線性交叉淡出，不突然斷掉高音量舊曲目。

重播退出的musicDuck恢復時間常數由40ms改為120ms，避免100ms內就從0.12回到約0.95。暫停／無曲目狀態維持40ms恢復，搭配既有180ms曲目淡出；以免音訊圖閒置時原生AudioParam讀值停在尚未恢復的中途狀態。播放中的語音優先增益、材質終結包絡及勝負播報不變。

新增真實Web Audio測試：重複清理仍保留15ms淡出、短音不能跨段、正常退出平滑回升且重複操作不補播、快速換曲最多兩首並驗證暫停與恢復。原始測試重現硬切、0.8秒短音殘留、最多10個曲目聲源及100ms恢復到0.946。探針亦追蹤初始曲目的ended，避免錯算殘留來源。另提供正式單人完整對戰、勝負播報中立即再戰及下一場Three/Two/One/Go各一次的流程回歸；既有精彩重播自然完成／暫停／跳過與v1～v5戰績重播仍保留。

未修改物理、能力值、隨機數、戰績格式或引擎；沒有新增依賴、逐幀混音工作或設定項目。瀏覽器驗證不代表實體iPhone／Safari、耳機或來電硬體驗收。
