# 戰鬥陀螺對戰遊戲企劃書（Beyblade X）

Nov 11, 2026 · @Will Lin

## 企劃概要

這是一款以 Beyblade X 世代為題材的 3on3 陀螺對戰遊戲：玩家從圖鑑挑三顆陀螺排定出場順序，在立體戰鬥盤上逐場對決，先取得 4 分者獲勝。

| 項目 | 內容 |
| --- | --- |
| 遊戲類型 | 卡牌收藏 + 物理模擬對戰 |
| 模式 | 1P 對電腦、2P 同機對戰 |
| 收錄範圍 | Beyblade X 的 BX、UX、CX 三條產品線，資料截至 2026 年 11 月 |
| 單局長度 | 3 到 7 場對決，約 3 到 5 分鐘 |
| 平台建議 | 網頁（桌機與手機瀏覽器），之後可包成桌面版 |

設計優先順序依你的要求排定：

1. **對戰效果**：戰鬥盤、碰撞、極限衝刺與終結演出是開發資源的第一順位。
2. **卡牌資訊完整度**：每顆陀螺都有型號、三段零件、屬性類型、六項數值與特性說明。
3. **戰績統計**：每局結算與長期紀錄，放在前兩項穩定之後。

陀螺外觀採原創造型，依屬性與零件特性設計，不重製官方產品造型與商標；理由與授權注意事項寫在最後一節。

## 對戰規則

一局採 3on3 賽制：雙方各選三顆陀螺並排定順序，依序一對一對決，先累積 4 分者獲勝。

### 流程

1. **組隊**：從圖鑑選三顆，同一戰刃不可重複。
2. **排序**：決定先鋒、中堅、大將。雙方順序同時公開，公開後不可更改。
3. **對決**：第 1 場先鋒對先鋒，第 2 場中堅對中堅，第 3 場大將對大將。
4. **延續**：三場打完無人達 4 分，回到先鋒依原順序再打，直到分出勝負。
5. **結算**：進入戰後統計畫面。

### 終結方式與得分

| 終結方式 | 條件 | 得分 |
| --- | --- | --- |
| 旋轉終結 | 對手先停轉 | 1 |
| 越界終結 | 對手掉入兩側的越界區 | 2 |
| 爆裂終結 | 對手爆裂槽歸零、零件解體 | 2 |
| 極限終結 | 對手被打進正前方的極限區 | 3 |

雙方同時停轉或同時出界判定為平手，該場重打。

### 玩家操作

每場對決玩家只做兩件事，保持節奏明快：

- **發射**：選落點（內側、中間、外側）與傾角，再用蒐力條決定初始轉速。蒐力條停在最佳區間可得 100% 轉速。
- **氣勢呼喊**：每場一次，按下後 2 秒內衝刺觸發率提高。用在對手靠近極限區時最有效。

### 模式

| 模式 | 組隊方式 | 操作 |
| --- | --- | --- |
| 1P 對電腦 | 玩家選完後電腦依難度選隊 | 滑鼠、觸控或鍵盤 |
| 2P 對戰 | 輪流選隊，選擇時遮蔽對方畫面 | 同機分鍵：1P 用 A/S/D 與空白鍵，2P 用方向鍵與 Enter；觸控裝置分上下半畫面 |

## 戰鬥系統

戰鬥用即時物理模擬算出結果，不擲骰：兩顆陀螺的六項數值轉成物理參數，在戰鬥盤上實際碰撞，誰先停轉、出界或爆裂就輸。

### 戰鬥盤

- 碗形盤面，越靠中央越低，陀螺自然往中心聚集。
- 盤緣有一圈齒軌。軸心咬上齒軌會瞬間加速，這就是極限衝刺。
- 前方正中一個極限區、左右各一個越界區，其餘為護牆。

### 每顆陀螺的狀態

| 狀態 | 初始值 | 變化 |
| --- | --- | --- |
| 位置與速度 | 由發射落點與傾角決定 | 受盤面坡度、軸心移動模式、碰撞影響 |
| 轉速 | 蒐力結果，滿分 100% | 隨時間衰減，持久越高衰減越慢；每次碰撞再扣一段 |
| 爆裂槽 | 等於抗爆裂數值 | 受到重擊時扣減，歸零即爆裂 |
| 傾斜 | 0 | 轉速低於 30% 後開始晃動，移動變得不穩 |

### 碰撞計算

每次接觸依相對速度算出衝量，再由數值修正：

```latex
J = v_{rel} \cdot \frac{2\, m_a m_b}{m_a + m_b} \cdot \left(1 + \frac{ATK_a - DEF_b}{100}\right)
```

- 衝量推開雙方，重量大者位移小。
- 衝量超過門檻時扣對手爆裂槽，極限衝刺中的撞擊扣兩倍。
- 低身位打高身位時衝量加 15%（上擊）。
- 左旋對右旋時，接觸會讓轉速低的一方從對手吸回少量轉速。

以上係數（15%、30%、兩倍）是起始值，要在平衡測試階段用批次模擬調整。

### 類型相剋

攻擊剋持久、持久剋防禦、防禦剋攻擊，平衡型無明顯優劣。相剋不另加倍率，而是由物理自然產生：

- 攻擊型在持久型轉速優勢生效前就把它撞出場。
- 防禦型承受攻擊型的撞擊，等它自己耗盡轉速。
- 持久型與防禦型都不移動，比的是誰轉得久。

### 電腦對手

| 難度 | 選隊 | 排序 | 發射精準度 |
| --- | --- | --- | --- |
| 初級 | 隨機 | 隨機 | 轉速 70% 到 90% |
| 中級 | 三種類型各一 | 隨機 | 轉速 85% 到 97% |
| 高級 | 選數值總和高且類型互補者 | 依玩家過往排序習慣猜測並反制 | 轉速 95% 到 100%，會用氣勢呼喊 |

模擬採固定時間步長與亂數種子，同一組輸入永遠得到同一結果，可用於重播與自動化平衡測試。

## 對戰畫面

對戰畫面是本作的第一優先：用即時 3D 呈現戰鬥盤，每次碰撞都有對應的火花、鏡頭震動與金屬撞擊聲，終結瞬間進入慢動作特寫。

### 場景與鏡頭

- **戰鬥盤**：半透明碗形盤面、發光齒軌、三個出界區以紅色脈動燈標示。
- **陀螺模型**：三段式結構（戰刃、棘輪、軸心），金屬材質帶環境反射。造型依類型與零件參數程序化生成，屬原創設計。
- **鏡頭**：預設斜 45 度俯視，隨兩顆陀螺的距離自動推拉；極限衝刺時低角度追身，終結時繞行特寫。

### 動畫與特效

| 事件 | 視覺 | 音效 |
| --- | --- | --- |
| 發射 | 倒數 3、2、1，陀螺帶殘影落入盤面 | 倒數提示音、拉繩聲、落地聲 |
| 旋轉中 | 轉速越高殘影越長，低轉速時機體晃動 | 持續轉動聲，音高隨轉速下降 |
| 碰撞 | 接觸點噴出火花，數量與衝量成正比；重擊時鏡頭震動 | 金屬撞擊聲，依衝量分輕、中、重三級 |
| 極限衝刺 | 齒軌亮起，陀螺拖出光帶，畫面邊緣加速線 | 齒輪咬合聲加上升的呼嘯聲 |
| 氣勢呼喊 | 玩家側 HUD 閃光，陀螺外圈光環 | 短促增幅音 |
| 爆裂終結 | 慢動作，三個零件分離飛散 | 爆裂聲加零件落地聲 |
| 越界與極限終結 | 慢動作，陀螺飛入出界區，該區爆出光柱 | 低頻衝擊音加終結音效 |
| 旋轉終結 | 輸家緩緩倒下，贏家特寫 | 轉動聲漸弱、勝利短樂句 |

### 抬頭顯示

畫面兩側各一組：陀螺名稱與類型圖示、轉速條、爆裂槽、目前比分、剩餘出場順序。終結時畫面中央打出終結名稱與得分。

### 聲音製作

- 音效用 Web Audio 即時合成或自製錄音，不使用動畫或官方素材。
- 轉動聲為循環音源，音高與音量綁定轉速；兩顆陀螺分左右聲道。
- 背景音樂分三層：選單、對戰、賽末點（任一方達 3 分時疊加緊張層）。

### 效能目標

桌機 60 fps、中階手機 30 fps 以上。粒子數量與陰影品質依裝置自動降級。

## 戰後統計

每局結束顯示本局成績與分數，並寫入長期戰績。

### 本局結算畫面

- **勝負與比分**：例如 4 比 2。
- **逐場明細**：每場的對戰組合、勝方、終結方式、耗時。
- **個別陀螺表現**：勝場數、造成的總衝量、最大單次衝量、極限衝刺次數、剩餘轉速。
- **本局 MVP**：得分最多的陀螺。
- **按鈕**：再戰一局（同隊伍）、重新組隊、回主選單。

### 分數計算

| 項目 | 分數 |
| --- | --- |
| 獲勝 | 1,000 |
| 每取得 1 分對戰分 | 200 |
| 極限終結 | 每次加 300 |
| 爆裂或越界終結 | 每次加 200 |
| 完封（對手 0 分） | 500 |
| 發射轉速 95% 以上 | 每次加 50 |
| 難度倍率（1P 模式） | 初級 1.0、中級 1.5、高級 2.0 |

### 長期戰績

| 統計 | 內容 |
| --- | --- |
| 總戰績 | 勝、敗、勝率、最長連勝；1P 與 2P 分開計算 |
| 陀螺戰績 | 每顆的出戰數、勝率、最常取得的終結方式 |
| 終結分布 | 四種終結方式各佔的比例 |
| 類型對戰表 | 四種類型兩兩對戰的勝率，用來驗證相剋是否如設計 |
| 最高分 | 單局最高分前 10 名，含隊伍與日期 |
| 最近對戰 | 最近 20 局的摘要，可點開看逐場明細 |

紀錄存在玩家裝置本機，可匯出與匯入 JSON 檔。線上排行榜列為後續擴充。

- **商標與授權**：Beyblade 與各型號名稱是 Takara Tomy 的商標。自用或粉絲作品可作為資料引用；若要公開上架或收費，必須取得授權，或改用原創名稱與世界觀。我不是律師，公開發行前請諮詢專業意見。
- **造型**：陀螺模型、圖示、音效全部原創，不複製官方產品外觀、標誌或動畫素材。
