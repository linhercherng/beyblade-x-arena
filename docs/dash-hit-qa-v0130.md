# v0.13.0 極限衝刺命中演出

日期：2026-11-12。變更範圍為播放速度、Arena鏡頭及特效、Audio撞擊音。物理引擎4、陀螺能力、碰撞計算、場次計分、備份及重播輸入均無變更。

## 演出與整合

- 由實際hit事件辨識：任一陀螺仍在650ms衝刺有效期、衝量至少3，且尚未判定終結。每次衝刺只接受一次，900ms顯示時間內不重播；冷卻中被略過的衝刺也會標記已消耗，避免延遲補播。
- 前35ms播放速度為0.12，其後至150ms為0.28，300ms前平滑回到1；只縮放固定120Hz物理步進的播放累積時間，未改DT、隨機序列、呼喊tick或結果。15–40秒門檻仍以模擬時間計，慢動作會略增牆鐘時間。
- 近鏡目標最多拉近14%，以兩顆距離、視野及畫布比例限制最近距離，再沿用依時間阻尼；全場鏡頭不套用命中特寫。命中立即解除顯示貼軌偏移，讓接觸位置更接近物理位置。
- 加強既有火花、接觸亮芯與短促衰減震動，命中帶藍白亮點及淡藍擴散環。衝擊環只有一個預建Mesh，240ms內淡出；沿用360粒子、4亮芯及既有拖尾緩衝上限。
- 使用預熱的重擊AudioBuffer，播放速率0.8、稍提高增益；配樂4ms內壓至0.18，150ms後平滑恢復。普通撞擊最多5聲部，第6聲部保留給衝刺命中；專用音不受普通35ms強度節流擋掉。
- 暫停凍結鏡頭、慢動作包絡及特效，並以15ms取消撞擊尾音。靜音、離開與終結同樣取消尾音；終結優先重設命中特寫。減少動態模式保留聲音與少量接觸點，省略慢動作、拉鏡、衝擊環、震動及閃光。

## 驗證

- 新增3項Node測試：真實衝刺辨識／重複節流、包絡恢復／減少動態／重設，以及四種自然終結在有無慢動作下的完整Battle狀態一致；每種案例確實觸發過慢動作。
- 4項衝刺命中瀏覽器測試與自然四種終結共5項專項通過。測試涵蓋桌機及390×844畫布，逐Mesh與Instance的真實頂點投影檢查完整模型未被裁切，包含暫停、恢復、全場鏡頭、終結優先與減少動態。
- 最大配樂下，先普通重擊再衝刺命中仍存在0.8播放速率的專用聲部；回歸量測音效峰值RMS約0.0668，當時配樂約0.00350，混音峰值0.127。這是AudioContext取樣，不等同喇叭響度。
- 手機比例持續3秒密集命中，取樣146幀，中位數16.7ms、p95 17.1ms，接受4次特寫。使用原始RAF幀間隔量測，只有動畫步進限制dt；幾何UUID穩定，混音峰值0.170。屬本機Chrome模擬，非實體手機保證。
- 66項Node測試及TypeScript／正式Vite建置通過，保留既有大型JS檔提示。完整41項瀏覽器回歸全部通過（10.5分鐘），包含單／雙人完整賽事、戰績重載、備份、v1–v3與現行引擎重播、低幀率時鐘、低速旋轉及開場動畫。

本輪不重跑62,340場完整平衡；沿用物理版本4並執行原有8,192場獨立保留樣本，維持類型40–60%勝率、15–40秒與終結分布門檻。尚未驗證實體手機、中階GPU、長時間負載或實體喇叭／耳機聽感。
