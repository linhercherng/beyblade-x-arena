# v0.22.1 英文開場語音

依使用者要求加入 Three / Two / One / Go shoot!，保留3秒開場、發射與物理規則。語音只由現有畫面倒數的單次更新與進入戰鬥觸發，不建立另一套計時器、不補播漏掉的階段。

## 製作與播放

本機VoiceStudio後端在檢查及啟動安裝程式後仍不可用，沒有下載模型或改用雲端。改用已安裝的Windows System.Speech / Microsoft David Desktop，Rate=1、Volume=100，逐段產生英文語音；以本機FFmpeg移除頭尾靜音、轉16kHz單聲道16-bit PCM，峰值正規化到23000/32768、淡入5ms及淡出15ms。片段長度為0.4364、0.3729、0.4518及0.6093秒，均能在原節拍內完成。

版本化的countdown-voice-data.json含四段原始PCM的base64；countdownSamples以明確little-endian轉Float32。資料約80KB，隨JS載入，不新增HTTP或語音服務依賴。現有使用者手勢首次啟用AudioContext時預熱四個AudioBuffer，後續回合重用。音源為本機TTS產物。

語音走原有SFX／master／limiter通道，gain=1.6；播出前12ms起音，配樂先降至25%、語句後恢復，數字及GO原有提示音降低為0.08。全域靜音照常有效，配樂音量0仍可聽語音。新階段先停止前段；暫停、離開、背景、耳機／通話中斷及靜音沿用stopEffects和來源追蹤，15ms淡出，沒有待播Promise或恢復後補播。

## 驗證

新增核心測試先因缺少模組失敗；三項瀏覽器測試先因沒有語音／方法失敗，再實作。四段樣本的長度、非靜音、安全峰值與有限數值通過；沒有WebAudio時仍可遊玩。實際Chrome AudioBufferSource驗證單人與雙人依3/2/1/0各播放一次；靜音／暫停／背景會停止聲源，恢復不補播。

本機15項音訊與倒數回歸全部通過，包括正式雙人流程、裝置／通話、時鐘停滯、倒數單次更新與開場取樣空窗。CI加入三項原生Chromium語音測試，保留完整平衡及舊版重播門檻。發布核對同一提交與公開站語音流程。未改物理、能力值、種子、戰績或重播資料。

目前仍沒有iPhone實機；Windows WebKit不提供AudioContext，不將上述音訊測試當成Safari實機聽感驗收。瀏覽器音訊圖驗證不等同於確認所有喇叭、耳機的實際音色與音量。


收尾：118項核心與正式建置通過；追加7項語音與P0效能檢查通過。正常單人／雙人開場的四段語音均收到原生ended事件，沒有提前stop；獨立程式審查無阻擋問題。CI與匿名公開站以最終提交核對，音訊內容隨同JS發布。


安裝驗收曾發現版本更新誤改meshoptimizer鎖定值，CI於npm ci即拒絕，未發布該狀態。已還原所有非根套件鎖定項，與基準逐項相同；乾淨npm ci成功、118項核心及正式建置再次通過。最終提交另由完整CI驗收。
