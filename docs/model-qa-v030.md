# v0.3.0 模型外觀驗收

日期：2026-11-12。以 v0.2.0 的 `8ffef4a59dbcfe9a8046cca8b1862914e7a7e9c7` 為基準。

## 交付

- 83 顆改用指定原廠組合俯視原圖；另有71顆斜視、45顆棘輪、46顆軸心照片，共245張，原始 bytes 與來源 SHA-256 保留。詳見 [圖片來源](model-references.md)。
- 共用於戰鬥及圖鑑的分層戰刃、底框、鎖定環、凸齒棘輪及軸心。54碼軸心依外形分類；已核對34碼官方詳解，20碼仍為外形近似。詳見 [零件幾何](part-geometry-references.md)。
- 一體式戰刃／棘輪或棘輪／軸心在拆解及爆裂時連接；0棘輪保留圓環，M棘輪保留金屬環。Silver Wolf 的自由環放在戰刃下層。
- 圖鑑可左右／上下拖曳、查看側面／底部及拆解；對戰加入近鏡，按畫面比例保留兩顆模型邊界。
- Nr 名稱修正為 Narrow、LP 修正為 Low Point；只改名稱，未改能力或類型。

## 驗證

- `npm test`：21項通過。包含83模型足尖接地、有限幾何／實例矩陣、三段結構、0與M棘輪、身位與一體式連接、平底封底與盤面接合、窄螢幕相機投影、245張來源雜湊、平衡、舊重播及備份。
- `npm run build`：TypeScript與Vite通過。仍有既存的單一JavaScript chunk大小提示。
- `npx playwright test`：最終9項全部通過（196.97秒）。涵蓋83張實物圖、6款BX/UX/CX／一體式的側面與拆解、手機390px、戰鬥近鏡、完整1P/2P、舊v1重播、戰績保存、匯入拒絕與低幀率時計。檢查截圖已保存在本機 `artifacts/model-*.png` 與 `artifacts/battle-close-*.png`。
- 與基準比對，`physics.ts`、`physics-v1.ts`、`legacy-stats.json`、`catalog-data.json`、`match.ts`及`storage.ts`無改動；原有40–60%勝率及15–40秒的回歸斷言通過。本次未另重跑完整24,464場稽核。
- 程式審查發現的拖曳抵銷、近鏡手機裁邊、平底空心及盤面懸空問題已修正，針對性幾何與投影測試通過。

## 驗證界線

本機Chrome的桌機／手機視窗測試不等於實體手機效能驗證。沒有做實物量測、CAD或3D掃描；厚度按系列近似、色碼按照片估算，未知齒輪採通用12齒。CX-09目前只展示藍面，沒有紅／藍面切換。照片與外觀不作為物理碰撞或性能規格。
