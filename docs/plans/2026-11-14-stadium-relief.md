# 盤體凹碗與細齒

保留白色塑膠盤體與藍色齒軌，增加中央下凹、過渡坡面、倒角接縫、實際板厚與底殼腔。細齒由320個角度槽增為384槽，扣除三個出口後由235顆增至285顆；斜削齒面、收窄齒尖及齒根、頂側不同材質與承載螺絲加強近景辨識。

僅改視覺高度。共用連續曲面函式，中心降低0.30，於半徑1.25～4.05平順銜接舊高度；外圈抓軌、出口位置與高度保留。陀螺、落盤環、撞擊特效、爆裂散件及重播鏡頭一起對齊，不改物理力、碰撞、種子、資料與舊引擎。

先用幾何高度差測試確認舊盤不符合目標，再實作；以實際盤面Raycast、模型貼盤、終結及重播驗證，對照同場景前後的三角形、draw calls與幀時間。重複件維持實例化，不加即時後製或新燈光。驗收與發布見 [v0.24.0](../stadium-relief-v0240.md)。
