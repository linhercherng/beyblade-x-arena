# v0.2.0 平衡與實物外觀 Implementation Plan

**Goal:** 四類型在等量對手及交換先後手的驗收樣本中各達40%–60%勝率，單場15–40秒；83顆卡片使用可追溯實物圖，戰鬥模型個別可辨。

**Architecture:** 保留固定120Hz即時物理與既有3on3/UI。先用可重現、對稱的校準／保留種子測出偏差，再調整零件及物理係數，不能抽籤決勝或丟棄不合格對局。模型使用產品圖片頂面貼圖、個別輪廓／配色與原有三段結構。

**Tech Stack:** 現有TypeScript、Three.js、Node test與Playwright；不新增執行時依賴。

## 風險

勝率是明確測試分布下的結果，不能宣稱任何隊伍或真人發射都必然40%–60%。單場下限應由實際物理與可見的規則達成，不能延遲既定勝負偽造時長。圖片對應逐顆核對，未核實部分不可標成已還原。舊戰績保留，物理升版以版本隔離重播。
