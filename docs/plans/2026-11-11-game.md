# 極限陀螺競技場 Implementation Plan

**Goal:** 依提供的企劃書建立獨立、可執行的繁體中文 3D 陀螺對戰遊戲。

**Architecture:** TypeScript + Three.js 的靜態網頁；純函式固定步長物理與 UI 分離。83 筆原廠組合從企劃書匯入，以獨立戰刃／棘輪／軸心表合成遊戲數值；原創程序化模型及 Web Audio 音效；IndexedDB 保存戰績。

**Tech Stack:** Vite, TypeScript, Three.js, idb, Node test, Playwright。

已有完整企劃，直接實作原廠組合，改裝、線上排行、桌面封裝依文件列為後續。效能與相剋數值需以實測報告界定，不能用宣稱取代驗證。產品待核資料不杜撰。

## 指令

`npm install`、`npm test`、`npm run build`、`npm run test:e2e`、`npm run balance`、`npm run dev`。

## 範圍與資料風險

只寫新專案，不修改父專案。歷史資料匯入只接受本遊戲版本及已知陀螺 ID；檔案大小受限，匯入失敗不覆蓋既有記錄。未核實發售日顯示未確認，所有數值標示遊戲平衡值。
