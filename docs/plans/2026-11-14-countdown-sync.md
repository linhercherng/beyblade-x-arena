# 冷啟動倒數與 Go Shoot

問題：總經過時間直接換算倒數，長幀會跳過數字；音訊未就緒時播放呼叫失敗後不重試，原生聲源啟動或結束較慢時也可能被下一拍取消。

改用四拍狀態，先呈現一幀再播放當拍；數字至少停留一秒，且等待聲源的 ended 才推進。沒有音訊支援或已靜音時使用視覺節拍；暫停／背景取消語音後，只在繼續時完成當拍。沿用現有語音優先混音與中斷清理，不新增背景計時器或語音佇列。發射模型進度保持單調，GO 後才推進物理，字樣保留至語音完成。

Go Shoot 保留 David 聲線，增加 Shoot 的音高與重音、延長尾音並加少量疊聲；聲源仍離線載入且峰值受控。不改戰鬥規則、種子、輸入、統計或重播格式。以長幀／延後聲源故障注入先確認失敗，再驗證完整播放、畫面對應、中斷重啟與舊戰績；完成後同步 GitHub 與公開站。
