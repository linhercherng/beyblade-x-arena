# v0.3.0 三段零件外觀 Implementation Plan

**Goal:** 戰鬥模型補上分層側面、戰刃厚度、棘輪凸齒及軸心接地形狀，盡量對應各卡原廠組合配色。

**Architecture:** 把3D模型建立移到可獨立測試的 `src/bey-model.ts`；保留既有Arena、三段爆裂動畫與物理。模型資料使用逐顆官方組合參考與逐軸心外形表，未確認項目清楚標近似，不用類型顏色冒充零件顏色。

**Tech Stack:** 現有Three.js（分層輪廓、旋轉曲面、InstancedMesh及環境反射）、TypeScript、Node test、Playwright；不新增執行時依賴。

## 工作及驗收

- [x] 核對83顆原廠組合的官方斜視／俯視圖、零件配色，下載原圖並記錄來源與確認程度；核對各軸心的實際接地形狀、金屬尖端與一體式結構。
- [x] 先寫模型測試，再實作三段細節：分層金屬戰刃及塑膠內架、正確數量凸齒的環形棘輪、按代碼區分的軸心；低／高身位與整合零件保留差異。
- [x] Arena共用新模型，維持爆裂三段物件契約及貼圖／幾何釋放；改善環境反射與檢視旋轉，讓側面和底部可查看。
- [x] 圖鑑預覽顯示原廠組合參考與外觀確認狀態，可拆解查看三段；戰鬥中使用同一模型。所有改動只影響繪圖，不修改平衡係數。
- [x] 跑模型／舊重播／完整賽制測試、瀏覽器組合／側面／拆解與完整對戰；用截圖和來源對照驗證，保存變更並更新原私人網站。

## 範圍與限制

不推測照片無法證實的內部機構，不添加外露彈簧或假零件。照片估算的厚度／側面不宣稱為CAD或實測毫米。保留83顆、現有戰績及兩代重播，物理、AI與計分不改。
