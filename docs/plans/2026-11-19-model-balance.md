# 型號平衡追查與修正 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 釐清 v0.43.0 的11款觀測旗標，僅修正持續失衡型號，維持四類40–60%、15–40秒及舊重播，發布兩端。

**Architecture:** 先保存原始觀測，再以全型號對手、四類等權、相同發射條件互換玩家側及兩批獨立種子追查。校準與保留驗收種子分開；若需能力修正，使用明示的型號校準資料，不改原廠零件／旋向／外觀或直接指定勝負。新對戰升引擎版本，舊版能力快照保持原結果。

**Tech Stack:** TypeScript、既有固定步進物理、Node test、Playwright、GitHub Actions、Sites。

實作清單記錄提交前進度；最終發布結果以同提交驗收產物與部署回傳為準。

## 驗收邊界

原旗標是等量型號對手，並非四類等量或實物強弱證明。新的追查會同時保留兩種加權，不能用改分母隱藏弱點；不同發射情境結果分列。若只在單一批次或邊界出現、獨立驗收不重現，不為消除旗標而調值。統計結論限本遊戲的預先列明情境，非真實陀螺實測。
