# P2 體驗改善

依既有優化清單實作四項：原廠照片近似模型細修、發射練習與教學、戰績重播跳轉和鏡位、備份預覽與版本相容性。

- 練習沿用實際發射與對戰流程，固定同型號對手，僅保留當次狀態，不新增戰績。以91款下拉選單沿用圖鑑旋向，不增加反轉原廠固定旋向的選項。
- 重播以原種子、發射、呼喊tick及原引擎重新模擬指定時間；關鍵碰撞最多5處、間隔至少0.75秒，不儲存每幀快照、不追播過往音效。保留原紀錄，完成後留在操作區。
- 備份使用既有解析驗證，先比較數量再讓使用者確認取代，取消不寫入，提交中禁止取消。維持格式v1及2MB上限。
- 模型精修限三款可由既有原廠照片核對的零件；採渲染覆蓋層，避免改動會影響個體特性的原始輪廓資料。不是實物CAD，沒有推定尺寸精度。

驗收：核心及建置、引擎1–5黃金紀錄、Chrome瀏覽器實際操作、模型側／底視檢視、手機窄畫面、完整平衡門檻。GitHub自動回歸納入P2流程。保留原物理引擎5與特性版本1，四類型40–60%、各樣本15–40秒門檻不放寬。
