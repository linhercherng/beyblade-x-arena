# v0.26.0 陀螺特性演出與開場音效

91款沿用現有實物參考配色、戰刃齒數、零件族群與遊戲特性估值，不用名稱或ID亂數決定強弱。各顆套用自身參數，呈現不同數量與尺寸的掃刃、護環、持久氣流；旋向依原有左右旋資料顯示。這些是遊戲視聽演出，並非實物能力量測或新增勝負技能。

- 攻擊型：分段刃狀掃光，依戰刃輪廓分瓣；高速移動與衝刺時增強。
- 防禦型：受擊時短暫展開多邊護環，火花較貼近戰刃高度。
- 持久型：雙層穩定氣流、較柔和的旋轉音色。
- 平衡型：依實際移速與傾角，在掃刃與護環間切換。
- 特殊零件：偏心軸使掃光外緣帶波動；自由環增加反向相對氣流、減低旋轉嗡聲；橡膠軸加寬衝刺拖尾。重量／接觸輪廓影響撞擊音高，抓軌估值影響拖尾寬度，移動與慣量影響尾跡長度。

原有碰撞事件的player固定為0，不能作為攻擊方；新版以碰撞當刻雙方平移動量選擇主要演出，再混用雙方配色。事件資料與物理均未更動。資料由WeakMap快取，兩顆陀螺分別保留受擊狀態；附加效果只新增兩組可重用薄帶網格，不逐幀建立幾何或材質。暫停凍結、重播定位重置，減少動態模式隱藏附加光環。

開場重新合成短促棘齒、發射器釋放與風切，One起音後450ms加入落盤低音，對齊原有2.45秒落盤動畫。仍由原語音播放狀態推進倒數，不改Three／Two／One／Go Shoot語音檔。語音維持獨立配樂／音效壓低通道，聲音預先合成且有起落包絡。One語音會先於落盤尾音結束，因此保留尾音參照到真正結束，讓暫停、靜音與背景清理仍能停止它。

檢查範圍包含91款資料有界、特效頂點、主攻方選擇、平衡型切換、合成波形、四類型畫面、特殊軸心、左右旋、幾何重用、暫停與物理資料不變、手機尺寸、減少動態，以及冷啟動倒數、高負載、配樂混音與尾音清理。原物理、能力數值、種子、規則、儲存格式與舊重播引擎保持原樣。完整平衡報告與v0.25.0逐項相同，66,708場均在15～40秒內。

本機Chrome及手機尺寸模擬可量測畫面與音訊訊號；未驗證iPhone/Safari、藍牙耳機或實際喇叭的主觀聽感。發布證據保留在本機artifacts及GitHub Actions。

雲端回歸補正：齒軌拖尾壽命原以10秒牆鐘等待，軟體WebGL低幀率時模擬時鐘尚未走完，導致誤判。改為fixture明確推進一秒模擬時間後驗證拖尾消失；暫停精確與不改物理檢查仍保留。CI的純效果檢查採640×480，完整桌面與手機效能門檻由本機既有測試驗證，沒有放寬特效終點判定或遊戲時鐘。
