# v0.10.0 戰鬥特色與終結平衡驗收

日期：2026-11-12。物理引擎4，圖鑑91款與原有能力值保留。

## 修正與遊戲規則

- 攻擊：外圈追擊與齒軌衝刺，衝量增加但耗轉與反作用力較高。
- 防禦：固定守中、減少受擊擊退，受擊後1.1秒內再次接戰有反擊加成。雙方條件在碰撞結算前讀取，不因玩家處理先後而異。
- 持久：小圈低速巡航、低耗轉與原有左右旋傳能，較怕強擊退。
- 平衡：週期切換守中與外圈進攻，四種終結都有勝機。

原盤緣門檻是2+60×轉速，高轉速時遠超平時7.5的移動限速；新門檻是0.8+1.5×轉速。出口角度與立體護牆共用側方0.24、前方0.29弧度。通過開口後保留離盤動量；若被反撞回護牆內側或動量朝內，即恢復操舵與護牆。終結依實際通過的出口種類記分，前方極限出口斜向滑出仍為3分。

爆裂傷害由極端集中在低轉速的8次方改為3次方，並分開校準擊退倍率2.1、鎖扣損耗14及受擊恢復1.1秒。前15秒保留最低3%轉速、40%原始鎖扣及盤緣保護，避免鎖扣一起降到零而在保護解除後大量同時爆裂。30秒後維持每方每秒額外耗轉0.11，左右旋傳能不增加總能量，仍在40秒前依場上狀態結束。

沒有依類型抽籤決勝或直接抽終結種類。15秒最低交戰保護及30秒耗轉在規則與時鐘階段標示說明；時長為1×模擬時間，不含降下、結算演出及暫停。
