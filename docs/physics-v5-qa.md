2026-11-13實作；2026-11-14完成發布前檢查。新對戰使用物理引擎5、特性規則1；既有戰績不遷移、不重算。

## 勝負如何產生

力量先轉成無因次輸入能量；依個體慣量、初始平移及傾角接地損耗分配轉速。傾角0–30°建立初始傾斜，而非只增加速度；落點決定初始半徑。偏內切／沿旋向／偏外切按各自左右旋解讀，影響初始行進方向與傾斜進動相位。畫面在固定120Hz物理步長之間插值傾斜軸，精彩重播也記錄這些姿態。

移除依時間正弦波指定目標半徑的導向。碗面回拉、接地摩擦、動量、軸心機動與隨旋轉相位改變的接地驅動形成路徑。旋向同時影響切向移動、進動及異向碰撞傳能。

驅動、齒軌衝刺及碰撞增加的平移能量由旋轉能量支付。每次驅動最多動用當下35%旋轉能量；不足時縮小可達速度，避免一步耗光或憑空加速。碰撞雙方先快照再一起提交付款與受擊耗轉，低轉速鏡像碰撞仍公平。異向傳能以慣量加權的旋轉能量交換，不直接等量加減rpm。

最後依場上狀態判定：離盤位置及通道、鎖扣耗盡、轉速耗盡；同一步雙方終結為平手。沒有勝率擲骰、比分補運或預先指定勝者。

## 逐顆特性與資料界線

`src/combat-profiles.ts` 規則1取代名稱雜湊。每顆使用既有原廠照片參考及零件資料；圖鑑詳情展示指數、估值說明與戰刃／軸心來源。

| 來源 | 推導特性 | 模擬中的作用 |
| --- | --- | --- |
| 72點輪廓比例、刃厚、類型基值 | 質量、慣量 | 擊退、初始轉速、付能預算 |
| 輪廓起伏、肩部落差 | 接觸指數 | 攻擊能力與撞擊強度 |
| 核心抬高、棘輪高度、輪廓起伏 | 穩定指數 | 傾斜回穩及防禦能力 |
| 軸心族群、足端半徑、偏心／自由環 | 機動、摩擦 | 初始移動、接地驅動及阻力 |
| 齒軌肩寬、軸心代碼族群 | 抓軌 | 衝刺能力與咬合門檻 |
| 棘輪高度、凸齒數及軸心基值 | 鎖定 | 初始抗爆裂能力 |
| 原廠旋向與零件高度 | 左右旋、接觸高度 | 轉向、異向傳能、低位上擊 |

以上都是可校準的遊戲估值，含類型基準，非實測公克、慣量、摩擦或官方強弱排名。照片不能證明內部質量分布；碰撞包絡仍為圓形，未實作完整三維剛體與真實材料接觸。規則1隨引擎5凍結；後續改值應新增特性／引擎版本並保留原規則。

每場種子固定三項小幅偏差：發射效率0.97–1.03、方向±2°、摩擦0.98–1.02。不是每幀抽取，也不讀取比分。備份保存種子、力量／落點／傾角／方向、呼喊tick、引擎與特性版本，因此可逐步重現。

15秒以前仍有最低3%轉速、40%鎖扣及盤緣保護，30秒後共同增加耗轉。這是明示的遊戲節奏規則，包含最低狀態補正；不宣稱整場為嚴格能量守恆的實物模擬。15–40秒指1×物理時間，不含降下、暫停、慢動作與精彩重播。

最終規則共71,076場；未針對個別場次覆寫勝負或延後已終結的結果。詳見 `balance-report.json`、`expansion-balance-report.json`。

| 集合 | 場數 | 覆蓋 |
| --- | ---: | --- |
| 校準 | 4,096 | 四類型等量對手、互換玩家側 |
| 獨立驗收 | 16,384 | 不同種子；65–100%力量、三落點、0–30°、三種方向及呼喊 |

| 新8款 | 4,368 | 各對全91款、三種子、雙方互換與隨機方向 |

獨立驗收勝率（平手計入出戰分母）：攻擊49.963%、防禦44.678%、持久49.719%、平衡48.328%。四類型整體皆40–60%；不是每個型號或每組相性的保證。停轉42.54%、爆裂17.04%、越界21.93%、極限18.49%，平手3.66%。攻擊衝刺多於平衡，平衡多於防禦／持久；攻擊爆裂勝場多於停轉，持久過半勝場為停轉，防禦盤外終結多於爆裂。

所有集合皆15–40秒，實際15.00–32.87秒，無超界案例。抽樣是統計驗收，不保證所有未測種子／玩家操作都保持相同勝率。
