# v0.15.0 終結精彩重播

日期：2026-11-12。範圍為戰鬥姿勢暫存、顯示／音訊播放及精彩重播介面。沿用物理引擎4、能力值、碰撞、出口、計分與戰績格式。

## 行為

- 爆裂、越界與極限終結先完成原2.3秒結果演出，再自動重看最後最多2.5秒戰鬥與終結。以0.55×慢動作播放，最多約7.55秒；重播時間不計入15–40秒模擬對決時長。
- 追擊鏡位與終結特寫分別使用不同方位；手機取景以當前相機注視點及兩顆顯示位置、貼軌偏移、爆裂散件與接盤包絡校正距離，避免阻尼落後造成裁切。只在精彩重播啟用。
- 保留清楚的精彩重播標籤、鏡位提示與進度條；「跳過重播」立即停止短音效並前往原結果。暫停或切換分頁凍結進度，離開會清理重播。旋轉終結、平手、減少動態模式及歷史完整重播不自動插入精彩重播。
- 使用已發生的姿勢與事件，不再次呼叫物理步進。終結及計分只使用正式Battle，重播複本不寫入戰績，也不嵌入備份。

## 資源與音效

- 30Hz紀錄姿勢，固定92格環形緩衝及最多128筆碰撞／衝刺事件，重用姿勢物件；重播起始才複製最後一段。位置與連續旋轉圈數插值，保留左右旋向。
- 重用原本兩顆模型、幾何、材質、火花、拖尾與終結動畫，不重新載入模型或錄製影片。重播沿用360粒子及6撞擊主聲部上限。
- 碰撞與衝刺依紀錄的時點播放；終結音效固定0.55速率，與動畫同速。暫停、跳過、離開及靜音清理音效，音樂仍經原混音限制器。

## 驗證

- 3項新核心測試涵蓋環形容量、最後2.5秒、重設與複本獨立、連續左右旋插值、事件上限／不重播、旋轉／平手／資料不足的排除，以及錄製前後完整物理狀態一致。
- 新增手機整段重播頂點投影檢查：實際自然爆裂／越界／極限輸入，60fps播放步進、每100ms檢查Mesh及Instance實際頂點。修正前自然越界最大NDC為1.209，取景補正後重測。
- 另驗證三種終結的雙鏡位、精確暫停、原結果不變、模型幾何UUID穩定、慢速音訊、跳過清理，以及實際遊戲暫停／跳過後只結算一次。
- 73項核心測試及TypeScript／正式Vite建置全部通過；保留既有大型JS檔提示。確認物理、能力值、計分與儲存原始碼沒有差異。
- 完整回歸的手機比例取樣108幀，中位數16.7ms、p95 16.8ms，混音取樣峰值0.146，模型幾何UUID不變。這是本機Chrome的原始RAF間隔量測，非實體手機保證。
- 49項瀏覽器完整回歸首輪48項通過（8.7分鐘），包含單／雙人完整賽事、精彩重播自然播完、暫停中跳過、只計分一次，以及開場、舊版重播、備份與原有效果。
- 一般重擊前景音量比較首輪未達1.5倍門檻（音效RMS 0.07849／當時音樂0.05818），未變更普通撞擊參數或測試門檻；隔離同項連續重測3次均通過（22秒），最後一次音效0.07009／音樂0.04213。短音訊峰值取樣存在時序差異，不能用單次bus RMS推定所有裝置的聽感；49項獨立案例均已完成驗證。

本輪不重跑62,340場完整平衡，執行原有8,192場獨立保留樣本，要求類型40–60%勝率、15–40秒模擬時長與既有終結分布。實體手機、中階GPU、長時間負載與實際喇叭／耳機聽感未驗證。
