# v0.24.0 競技盤細節與高低差

中央曲面由舊版中心 -0.03、外緣0.4035，改成中心 -0.33、外緣0.4035，高低差從0.4335增至0.7335（約69%）。半徑1.25以內為內凹中心區，1.25～4.05以平滑曲線過渡至原外緣。中央增加有厚度的倒角環、細接縫與偏冷的凹面明暗，外側保留白色塑膠肩面。碗底與底殼也調整為可容納凹碗的曲面與腔體。

整圈齒槽從320增至384，避開三個既有出口後，實際細齒由235增至285。八點非對稱齒形、斜削頂面、倒角與較深側面材質，配合齒根承載通道及小螺絲，使齒軌近鏡具有厚度與咬合方向。重複件使用 InstancedMesh；沒有新增陰影燈、折射或全畫面後製。

新的 stadiumSurface 只控制顯示高度，所有 x/z 物理、抓軌區間、出口判定、分數與資料格式保持不變。戰鬥模型、開場落盤環、火花、爆裂散件、停轉側躺與光環及精彩重播追蹤使用同一個高度函式；盤外高度封頂，避免爆裂散件懸空。舊戰績仍沿原版引擎產生 x/z 軌跡，再套用新盤體顯示。

幾何測試先確認舊盤高度差不足而失敗，再驗證新曲面、細齒與出口。實際 Raycast 確認模型在中心、斜坡與齒軌內緣的高度一致；終結、戰鬥、桌面／手機版面既有七項回歸通過，盤體三項回歸通過。初次新增接觸測試使用了無法由瀏覽器直接解析的 bare three 動態匯入，已改由 fixture 提供同一個 Three.js 模組後通過，未修改遊戲以配合測試。

補查停轉演出時修正原本固定高度的光環，並讓側躺整顆模型按實際包圍盒抬到盤面上；先新增穿盤回歸測試確認失敗，再實作，零件相對位置保持不變。為遵守原有45個繪製物件預算，移除額外的獨立接縫環，由中心倒角本身呈現接縫。幾何與終結12項核心檢查及7項盤體／終結瀏覽器檢查通過。

最終129項核心與正式建置通過；獨立程式複查無阻擋問題。完整平衡報告及公開站驗證由發布產物保存。鎖定檔所有非根套件與基準逐項相同，未新增相依套件。
