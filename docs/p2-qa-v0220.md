# v0.22.0 P2 驗收

本輪依既有P2清單改善四項，沿用既有元件、發射流程、IndexedDB及重播引擎，沒有新增依賴。

## 外觀

蒼穹龍騎士BX-34、玄冥戰甲BX-35、武士星劍UX-09：細修透明棘輪內件、C／D／L軸接地外形和戰刃側緣。詳見[原廠照片及近似範圍](p2-model-refinements.md)。由渲染後處理加入，不修改會影響特性的model-profiles、part-shapes、catalog或combat-profiles。三段爆裂群組和接地邊界保留。

## 發射練習與教學

首頁可進入，91款陀螺可選並顯示左右旋；教學涵蓋落點、0–30°傾角、內外切及蓄力。對照方用相同陀螺、90%力量、中間落點、10°、沿旋；固定種子方便比較，玩家照常鎖定蓄力並可呼喊。實際結果顯示雙方保存的發射及碰撞數據，重練保留角度與落點。練習不寫入局數、連勝、每顆紀錄或最近賽事；瀏覽器比較練習前後完整備份一致。

## 戰績重播

拖曳時間軸、關鍵碰撞按鈕、追蹤／俯視／側面鏡位。每次跳轉使用原引擎、種子、發射和呼喊tick重播到指定時刻，然後暫停；不補播過去音效，也不改寫原紀錄。碰撞選本場最強且至少相隔0.75秒的最多5處，並附開場及終結。不是所有碰撞的完整索引。

完成後保留操作區並顯示「從頭重播」；終結動畫期間的手動暫停／繼續不會回到開場。關鍵點只在開啟重播時計算一次，拖曳時僅更新時間預覽，放開才重新模擬，不建立逐幀快照。此設計避免每幀模擬或增加歷史格式。

## 備份與相容性

沿用格式v1及2MB上限，先以原解析器驗證，再預覽本機與備份的單人／雙人局數、最近賽事、可重播回合及引擎版本。明示取代全部、不合併，取消不寫入；確認後以原IndexedDB交易保存。提交中顯示儲存中、停用取消及Escape關閉，失敗可重試或取消。新增v5固定黃金紀錄，v1–v4原始fixture不變；核心測試核對v1–v5終局完全相同、跳轉可重現且原紀錄未修改。
