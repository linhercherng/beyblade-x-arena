# v0.38.0 主選單與選隊音訊交接

主選單、重新選隊與單人／雙人切換共用menu配樂。原先home只在精彩重播存在時順帶清音；startTeam沒有完整清理。同曲切頁時，音訊引擎不會重新進入曲目轉換，可能留下短音或上一段終結的長退讓。原始回歸重現了短音未取消，以及返回主選單後musicDuck仍停在0.25。

home在既有clearHighlight後呼叫stopEffects；startTeam先清除精彩重播，再呼叫stopEffects。沿用原本15ms尾音、語音優先退讓釋放、短音／摩擦音清理與配樂柔順恢復。音訊引擎本身未修改；沒有新增逐幀清理，避免把發射頁新產生的鎖定提示音取消。

stopEffects不改音樂requested、playing或offsets，因此模式切換與重新選隊仍沿用同一首menu來源。切離對戰時保留原本的離開確認流程，不會因音訊修正而跳過確認、結算未完成對戰或寫入額外戰績。

新增四項真實Web Audio／實際UI回歸：同曲返回主選單解除普通終結的退讓且保留音量；同曲等待仍保留新鎖定音；主選單／選隊／兩種模式間反覆切換，原生短音被取消、menu配樂來源保持相同；實際暫停→離開確認→返回主選單→重新選隊，配樂恢復且無舊倒數。測試以原生Sound call-through觀察main實例，未替換音訊播放、資料或物理計算。

原始碼下新測試2項失敗、2項通過；接上頁面入口後通過，並保留既有重播退出、倒數、材質終結、裝置恢復及v1～v5舊戰績回歸。沒有新增依賴、選項、音檔、音量設定、引擎或存檔欄位。瀏覽器驗證不代表實體iPhone／Safari、耳機或來電驗收。
