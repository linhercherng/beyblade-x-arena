# v0.12.0 齒軌咬合與極限衝刺驗收

日期：2026-11-12。範圍為Arena顯示、Audio音效、衝刺文字及測試。物理引擎4、能力值、場次計分、備份及重播規則無變更。

## 演出

- 咬合事件先將顯示姿勢短暫貼至軌邊（35ms），120ms內平滑追上實際物理位置；沿移動方向加入最高0.13弧度的傾斜，740ms內收束。只改顯示模型，不改Battle狀態。
- 兩個預建RGBA拖尾Mesh，淺色線芯與藍／橘速度帶，每條最多30點、174個有效三角形頂點；以時間取樣及380ms路徑長度減少不同幀率差異。
- 接觸點使用既有火花與4個flare的固定池，桌面單次最多24個、手機12個、減少動態4個；全局粒子仍以360為上限，同玩家120ms內不重複觸發。
- 出口角度與盤體共用設定；三個缺口不產生貼軌偏移、咬合火花或齒鳴，但保留實際衝刺的風切與速度帶。
- 衝刺文字改按模擬時間到期，暫停時不會被獨立timeout清除。

## 音效

兩種0.62秒原創合成波形：含齒鳴與風切、只有風切。首次解鎖AudioContext時預熱，交戰事件只取快取AudioBuffer。每玩家一個主聲部、120ms節流，替換時以15ms淡出舊聲；結束後斷開節點。暫停、隱藏頁面、靜音、離開及終結會取消衝刺聲。配樂先在4ms內壓低，再於8ms啟聲，保留咬合前景；220ms後平滑恢復。

44100/48000Hz單元驗證合成音有限、非靜音、峰值不超過0.85且尾音歸零。最大配樂與雙方同時衝刺的本機AudioContext實測如下（量測音效bus及音樂bus，不等同喇叭響度）：

- 音效峰值RMS：0.0719，當時配樂RMS：0.0043，比值16.65倍。
- 混音取樣峰值：0.1325；密集事件測試仍低於0.95。

- 63項Node測試全部通過：動態包絡、三出口、兩音色在兩取樣率的有限波形，及原有規則、平衡、重播與備份測試。
- 5項衝刺瀏覽器專項通過，涵蓋貼軌、速度帶、模型不改物理、暫停凍結、聲部取消、密集事件、減少動態、出口空隙；完整回歸涵蓋37項案例：首次36項通過，1項因恢復播放後的截圖耗時漏抓短暫下降階段；將暫停截圖移至恢復播放前（不改產品動畫時序），3項開場檢查重跑全部通過，37項獨立案例均完成驗證。完整執行11.1分鐘，開場重跑1.3分鐘。
