# v0.28.0 終結辨識與接觸修正

使用者回報「模型接觸卻沒有撞擊」的原因是戰刃實際繪圖半徑0.52、物理碰撞半徑0.39。戰鬥模型依快取頂點縮放至既有碰撞範圍，傾斜時以戰刃中心對齊物理位置。圖鑑仍保留原比例。齒軌命中時解除視覺咬合鎖定，避免畫面拖住陀螺而錯開碰撞。爆裂零件落地的世界抬升量也補償局部縮放。

碰撞與衝刺的來源配色延續到爆裂、越界、極限終結；終結色只作混色提示。特殊零件光環跟隨爆裂戰刃，拋出尾跡由原色漸變終結色；左／右旋決定旋流方向，彈簧與偏心零件帶有限的回彈。保留原路徑終點、固定粒子池及幾何緩衝。減少動態設定關閉新增動作。

終結聲使用敗方既有特性濾波，維持音源速率、長度及播報壓低配樂的流程。濾波隨音源結束清理。精彩重播及一般戰績重播顯示雙方中文名稱、旋向、軸心代碼與零件特徵；由現有陀螺資料推導，不新增存檔欄位。

驗證涵蓋91款戰刃範圍、傾斜對齊、齒軌高度，實際引擎接觸與冷卻期間仍分離，縮放後爆裂落地保護；瀏覽器檢查接近／反彈、預覽、三種終結與橡膠／自由環／左旋／彈簧組合、暫停、音訊濾波及重播提示。

完整66,708場平衡報告與v0.27.1逐欄相同；正式驗收16,384場類型勝率為攻擊49.963%、防禦44.678%、持久49.719%、平衡48.328%，所有批次時長15～32.867秒。物理引擎、能力值、隨機種子、舊引擎及儲存格式未變更。
