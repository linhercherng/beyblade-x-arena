# v0.30.0 斜坡滑行、反彈與齒軌交接

原本受撞會立即清除齒軌鎖定，模型從貼軌位置跳回物理座標；衝刺傾斜直接使用當下速度，反彈時會瞬間反向。貼盤雖已使用模型支撐點，姿態切換仍可能造成高度突變。新增單元案例先重現斜坡上傾角在一幀直接翻轉0.5 rad的問題。

沿用既有BowlContact，在不含自轉的盤面姿態四元數上做時間式平滑，再疊上原自轉相位。衝刺速度方向的傾斜也進入現有低通；受撞回彈仍使用v0.29.0的有界衰減波形。齒軌傾角依既有咬合曲線疊上，不平滑自轉，也不改齒輪接觸半徑。

受撞記錄一次解除時間，貼軌偏移在原咬合生命週期內指數淡出，二次碰撞不重啟解除時間。模型與對手距離小於1.58單位時逐步退出，距離等於兩個既有碰撞半徑時權重歸零，戰刃中心回到原物理位置。出口仍沿用無齒軌判斷。精彩重播鏡頭也涵蓋淡出中的貼軌位置。

高度每幀依平滑後的實際姿態及快取支撐點重新求解，保留0.004場景單位視覺間隙，不對世界高度另做低通，以免下坡懸空或上坡穿盤。暫停不推進姿態；重設、換場與舊戰績重新定位可直接初始化。所有變更位於呈現層，物理引擎、能力值、傷害、隨機種子及存檔格式保持原樣。

驗證涵蓋91款既有貼盤／齒軌與碰撞中心檢查、左右旋自轉相位、斜坡來回滑行、密集碰撞、受撞解除不瞬移、接近對手預先退出、反向及暫停、長畫格、幾何重用與減少動態模式；並回歸終結、精彩重播、v1～v5戰績及完整66,708場平衡報告。

舊齒軌測試原比較模型根節點半徑，已改比v0.28.0起的戰刃中心契約；減少動態姿態斷言改用1e-12浮點容差，仍檢查沒有新增回彈、震動或過量粒子。Linux CI沿用確定性案例，實際手機FPS與觸控仍需實機驗收。

尚未驗證iPhone／Safari實機與耳機聽感。
