# v0.27.0 專屬碰撞、衝刺與開場同步

沿用91款原配色、刃形、旋向與零件資料；變更只在呈現層。已確認的金屬軸、彈簧BS、橡膠、偏心及自由環，分別推導火花擴散、上揚、捲曲、衰減與衝刺脈動。未確認軸齒數沿用模型既有12齒近似，音高／摩擦聲與尺寸均為遊戲表現參數，不宣稱實物量測。

碰撞火花及其線狀尾跡共用各顆配色；同向碰撞呈現較短的同向剪切，反向碰撞形成雙色反向捲流及短暫接觸環。旋向跟隨陀螺資料，交換1P／2P不會反轉。衝刺依各顆慣量／軸心與既有抓軌估值調整尾跡寬度、脈動、掃光、播放速率及濾波音色；金屬齒鳴較亮、橡膠較低沉、偏心與彈簧帶不同節奏。畫面中的衝刺提示補上玩家、旋向和軸心代碼。

沿用固定360粒子、兩組特性薄帶與原拖尾緩衝，新增尾跡顏色屬性，不逐幀建立幾何／材質或新增燈光。曲線只旋轉視覺粒子的水平速度，不回寫Battle。音訊仍保留兩個衝刺聲部及既有碰撞上限，濾波器隨聲源結束清理。減少動態模式停用反旋接觸環與動態光環，保留少量接觸提示。

開場原本以畫格牆鐘決定降下、音訊時鐘排落盤低音，且GO文字出現時就先啟動發射特效。新版讓每拍提供實際AudioContext播放進度，落盤動畫及One後450ms低音使用同一時鐘。暫停補償音訊實際流逝，音訊停鐘時不以牆鐘誤推進；恢復當拍保持動畫不回跳，已觸盤則不重複排落盤聲。

GO文字仍先繪製以保留完整語音與畫面對應，但速度線、3D發射脈衝與開始移動等待實際起音。發射演出單次交接音訊相位，扣除下一次繪圖的時間增量，避免長畫格重複加算；若整段已結束，不補播延遲閃光。靜音／無WebAudio沿用原逐拍後備流程。動畫測試依交接時的實際相位判斷亮起／結束，不把低幀率誤當漏特效。

測試涵蓋91款參數範圍、左右旋交換、特殊軸心、受控畫格拖尾、雙色火花、幾何重用、音訊來源速率、暫停／背景／冷啟動、完整倒數、落盤及發射相位。140項核心測試通過。完整66,708場平衡結果與v0.26.0相同，各類型驗收勝率仍在40%～60%，對決15～32.867秒。物理、能力數值、隨機種子、儲存格式與舊引擎保持原樣；舊戰績重播及正式發布另由瀏覽器／CI驗證。

最初新增的fixture只記錄一個位置，尚未形成可見拖尾就截圖，已改成兩個明確推進的畫格。新增零秒計時檢查接受既有00.0格式，沒有為測試改動遊戲計時。CI只驗證確定性的長畫格相位與已落盤取消，精細的起音／畫面時間差由本機瀏覽器檢查，不當成軟體WebGL的FPS門檻。
