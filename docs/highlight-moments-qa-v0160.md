# v0.16.0 精彩重播定格與追蹤

日期：2026-11-13。範圍為精彩重播時序、顯示鏡頭及提示。物理引擎4、陀螺能力、碰撞、出口、正式計分及戰績格式不變。

## 演出

- 在最後2.5秒內，挑選一次衝量至少3的最強撞擊，定格120ms；終結瞬間定格160ms。撞擊距終結不足100ms模擬時間時合併，只保留決勝定格，避免緊連兩次停頓。全段最多增加280ms，最長約7.83秒，仍可一鍵跳過。
- 牆鐘進度與動作進度分開。定格時姿勢、旋轉、火花與終結動畫不推進，鏡頭仍可平滑追向接觸點；玩家手動暫停或切換分頁時，兩個時鐘一起停止。終結跨界不會將前段追擊時間算入散件或出界動畫。
- 追擊鏡位加入少量移動方向預判；撞擊定格看接觸點。終結鏡位以2:1權重追隨落敗陀螺，越界／極限使用實際動畫軌跡位置。預設近鏡依兩顆與落盤位置決定距離；全場選擇保持全景。
- 取景包絡使用當前兩顆顯示位置、貼軌位置、爆裂散件及出界軌跡，補償相機阻尼並避免裁切。校正只在精彩重播有效，仍重用既有模型、緩衝與粒子池。
- 全場選擇額外保留半徑6.5的完整盤體球形包絡，再補償目前注視點偏移；近鏡仍只追蹤兩顆與落點。盤體實際頂點最大原點半徑約6.279，無需新增幾何。
- 新增終結類型色標：「爆裂終結 · 三段分離」、「越界終結 · 側盤出界」、「極限終結 · 前方出口」。另依時刻顯示「關鍵撞擊 · 定格回看」、「決勝瞬間」及「慢動作回看」，只在文字改變時更新DOM。
- 碰撞聲在命中時播放，終結聲等決勝定格釋放後才啟動，保持0.55倍音畫同步。跳過、離開及靜音沿用原清理；減少動態模式仍略過自動精彩重播。

## 驗證

- 新增3項核心測試：三種中文提示、最強撞擊／終結定格與事件不重播、近接合併及時序上限，包含負值／非有限dt和原Battle不變。
- 新增定格瀏覽器案例：動作與模型位置不變時，鏡頭可追蹤；手動暫停完全凍結；決勝瞬間不提前播放出界動畫。自然extreme案例有獨立關鍵撞擊，over／burst案例則依合併規則只有決勝定格。
- 原有三種終結的整段Mesh／Instance頂點投影、雙鏡位、音訊、跳過及實際遊戲計分檢查持續執行。普通對戰／歷史重播的draw呼叫沿用原時間預設值。
- 76項核心測試、TypeScript與正式Vite建置全部通過，保留既有大型JS檔提示；8,192場保留樣本通過原門檻，物理／能力／計分／儲存原始碼沒有差異。
- 9項精彩重播與原終結銜接專項通過；最終重跑的手機比例專項112幀，中位數16.7ms、p95 16.9ms，混音取樣峰值0.143、模型幾何UUID穩定。數據為本機Chrome原始RAF間隔，非實機保證。
- 50項完整瀏覽器回歸全部通過（9.3分鐘），涵蓋單／雙人完整賽事、舊版重播、備份與原有效果。
- 完整回歸後新增全場盤體檢查，重現最大NDC約1.559的裁切；補上全盤球體下限後，包含此案例的6項精彩重播測試全部通過（1.9分鐘），76項核心與正式建置再次通過。合計51項獨立瀏覽器案例完成驗證。

本輪執行原有8,192場獨立保留樣本，要求類型40–60%勝率、15–40秒模擬時長與原有終結分布；不重跑62,340場完整平衡。重播定格不會改變正式結果。實體手機、中階GPU、長時間負載及喇叭／耳機聽感尚未驗證。
