# v0.17.0 精彩重播混音與決勝撞擊

日期：2026-11-13。只調整聲音演出；物理引擎4、能力值、勝負、計分、重播時間軸與戰績格式維持原版。

## 演出與資源

- 重播追鏡維持68%配樂，關鍵撞擊定格降至24%／1kHz低通，決勝定格降至18%／700Hz低通。進入定格以12ms收斂；釋放以80ms回到55%配樂／16kHz，返回原流程以80ms恢復正常音色，沿用既有碰撞自動壓低。
- 關鍵撞擊與決勝瞬間各有一次原創低頻／金屬強調音，決勝較沉。1.5ms起音、短衰減及尾端包絡避免突切；兩段波形首次啟用音訊時預熱，重播迴圈不合成樣本。沿用最多6個撞擊聲部。
- 決勝定格釋放後才播放對應終結聲，保持0.55倍音畫同步並提高重播終結聲強度。強調音以65ms淡出銜接，配樂不中斷、不從頭重播；保留使用者音量與全域靜音。
- 碰撞依攝影機右向量換算左右聲道；定格強調音與終結聲以45ms時間常數跟隨鏡位。轉子聲在追鏡時略降音高與音量，定格時進一步收低。
- 暫停、跳過、離開與靜音會停止音源及尾音，恢復配樂增益、濾波與自動壓低。同一次定格只強調一次，恢復或取消靜音不補播舊撞擊；下一段重播才重設。
- 不新增音樂檔、依賴、粒子或模型；一般對戰的撞擊參數不變。
