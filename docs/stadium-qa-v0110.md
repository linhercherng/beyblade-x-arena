# v0.11.0 立體盤體與細齒驗收

日期：2026-11-12。範圍為盤體幾何、材質及顯示版本；物理引擎4、圖鑑能力值、戰績與備份程式均無差異。

## 外觀

- 環形齒軌由99個方齒改為235個斜面倒角齒，採320分度，三個出口留空並加邊界間距。
- 增加連續齒根通道、雙邊壓條及實例化支撐肋，底盤改為分層倒角剖面。
- 外框側面凹槽與上緣斜面是實際幾何；六個出口端面有封閉端蓋，從出口外側射線皆可命中。起始端蓋明確反轉繞序與法線，避免背面剔除透空。
- 碗面增加頂點色曲率漸層及透明保護漆反光，不使用折射材質。盤面高度維持r²×0.024−0.03，三個出口角度沿用共享設定。

## 效能與邊界

盤體從41個繪製物件、33,646個三角形，增加為44個、60,908個；重複件總實例550個。新增細節主要採InstancedMesh，沒有為每顆齒建立獨立繪製物件。

本機Chrome隔離場景使用與遊戲相同的盤體、光源、環境反光與陀螺模型，取暖機後requestAnimationFrame間隔；不代表實體手機或所有鏡頭的效能上界。

- 60項Node測試通過，包含盤面高度射線、三個護牆出口、六端蓋可見性、凹槽實際深度、有限頂點及實例化預算；原有獨立8,192場平衡保留樣本仍通過40–60%勝率、15–40秒及終結分布門檻。
