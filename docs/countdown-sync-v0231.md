# v0.23.1 倒數同步與 Go Shoot

冷啟動及高負載曾因總經過時間跳到下一秒而略過某個數字。現在每拍先呈現畫面，再開始相同的語音；至少呈現一秒且收到原生聲源完整結束事件，才進下一拍。卡頓只延長開場，不壓縮剩餘數字，也不在背景排隊喊聲。

首次或中斷恢復後，先等原有總音量 250ms 淡入完成，避免首字在音量接近零時播出。音訊尚未就緒時保持當拍並沿用恢復提示；使用者仍可選擇靜音遊玩。無 Web Audio 的裝置保留逐拍畫面。暫停、背景或耳機／來電中斷會停止聲源，明確繼續後重新完成中斷那一拍，已完成數字不補播。降下動畫不回跳。

等待首字時也納入既有音訊停鐘監測，包含配樂音量為零、尚未建立語音聲源的情況；回報 running 卻不前進時會暫停並提供恢復操作，避免永久等待。審查發現此邊界後，已先用核心故障注入測試確認失敗再修正，保留原有長幀取樣寬限。

GO 字樣與原有發射特效先呈現，再播放 Go Shoot；物理於 GO 播放啟動後推進，字樣保留到語音結束。固定步長、種子、能力值、勝負、15～40 秒戰鬥計時與舊重播引擎不變。開場等待不計入單場戰鬥時長。

Go Shoot 使用本機 Microsoft David Desktop / System.Speech，Go 設 pitch=+3st、rate=+18%，45ms 停頓後 Shoot 設 pitch=+6st、rate=-12%，兩者 strong emphasis、x-loud。後製沿用 100Hz 高通、2.6kHz 存在感提升、3:1 壓縮及限制器，另混入 18ms／12% 疊聲，正規化至 23500/32768，淡入5ms／淡出15ms。片段 0.87025 秒、峰值 0.7172；數字三段保留原資料。配樂與音效在整句期間仍維持語音優先的音量平衡。

驗收：核心狀態機測試先因缺少模組失敗；原生 Chrome 快速對戰注入 2.2 秒 RAF 空窗，舊版漏拍，新版四段依序播放且 DOM 與語句相符。另驗證首拍延後 1.2 秒、暫停／背景接續、靜音及無 Web Audio，以及原倒數／發射／配樂回歸。測試中的背景事件注入不代表 iPhone 實機驗收；仍未確認實機喇叭、耳機及 Safari 的聽感。

本機驗收：原生冷啟動、發射呈現與倒數 15 項通過；單雙人完整勝負、終結語音、冷啟動及 v1/v5 匯入重播 13 項通過；修正停鐘監測後，路由中斷、冷啟動／停鐘恢復及開場空窗 15 項通過。初次取消計數探針將同一聲源的兩次 stop 誤計成兩次截斷，已改為每個聲源只記錄一次；實際播放序列不變。獨立程式審查提出的等待期停鐘邊界已補測並修正，複查無阻擋問題。最終 CI 保留完整平衡門檻並新增七項負載／恢復回歸。

最終核心 126 項及正式建置通過。沒有新增相依套件，package-lock 非根套件逐項保持原值；語音只更新 Go Shoot 片段，三段數字及所有終結播報保留原資料。
