# v0.33.0 軸心材質摩擦音色

沿用實際軸心資料與BeyEffects判定：MN／MT金屬軸、RA橡膠軸，其餘為塑膠音色。這是依材質設計的合成演出音效，不是實物收音；不改寫零件資料、能力、物理或勝負。

## 音色與同步

三組0.6秒循環在啟用音訊時預熱及快取。金屬使用高頻細刮與短週期共鳴，塑膠使用中頻乾澀顆粒，橡膠使用低頻黏滯及抓地脈動。44.1／48kHz以時間常數產生濾色，20ms交叉混合循環接縫，原始樣本峰值保留0.59上限並將RMS能量控制在相近範圍。

FrictionFrame攜帶材質，仍從同一繪圖姿態、插值轉速、旋轉相位與stopMotion產生音量。材質截止頻率隨擦盤脈動，側倒回穩時逐步收斂。音量上限0.25、25ms淡化、原SFX限制器／語音優先與配樂退讓全部沿用。

精彩重播聲源速率與濾波頻寬都沿用HIGHLIGHT_RATE=0.55；畫面、搖晃、側倒相位也使用同一慢放進度。撞擊／決勝定格關閉摩擦，恢復只播放當前相位；暫停、靜音、跳過、定位、中斷與離開盤面清理舊聲源。

每位玩家最多一個聲源。材質改變時先標記closing並淡出，等ended按身分清理後才建立目前材質，不重疊新舊音源；一般擦盤、側躺與停轉沿用同一聲源及快取。

## 驗證

單元測試涵蓋材質差異、高中低頻變化、相近能量、安全峰值、循環接縫與停轉相位。瀏覽器使用實際MN／F／RA陀螺，檢查快取選擇、慢放速率與動畫時鐘、定格靜音、側躺聲源重用、終點清理及反覆換材質；並回歸既有音訊中斷、v1～v5舊戰績、公開雙模式及平衡報告。

不新增設定、外部音訊資源、相依套件或存檔欄位。瀏覽器與離線Web Audio量測不等於iPhone／Safari、實體耳機與來電硬體驗收。
