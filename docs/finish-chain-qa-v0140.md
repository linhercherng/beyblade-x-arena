# v0.14.0 衝刺命中與終結銜接

日期：2026-11-12。範圍為Arena顯示、Audio音效及播放接點。沿用物理引擎4、能力值、碰撞與出口判定、計分、固定tick輸入及備份格式。

## 演出

- 最近450ms顯示時間、650ms模擬時間內的有效衝刺命中，可銜接爆裂、越界或極限終結；同一步命中並決勝也會記錄接點。旋轉終結、平手、過期接觸與減少動態模式不套用慢速交接。
- 終結動畫初速0.35–0.6，220ms內線性恢復1；視覺位移使用速率積分，音效AudioBufferSource同樣設定播放速率斜坡。最多增加71.5ms演出時間，仍在原2.3秒結算窗口內，沒有延後正式計分。
- 保留命中當下鏡位與注視點，以360ms smoothstep過渡至終結目標；爆裂逐步放寬取景以容納散件，越界／極限拉回接盤全景。依相機FOV與畫布比例，完整全景取景半徑至少6.5，避免側盤外緣或前盤的傾斜模型被裁掉。
- 命中殘留火花與亮芯轉成各終結色，衝擊環180ms內淡出，不重複補一組決勝撞擊火花。出口軌跡沿終結播放進度延伸，使用既有18點幾何。
- 保留原爆裂、拋物線及極限直衝的不同軌跡；不增加粒子、亮芯、拖尾或幾何池上限。暫停凍結所有演出進度；減少動態維持穩定終點。

## 音效

- 5種場次終結波形在首次音訊解鎖時預熱，交接時直接使用快取。命中尾音65ms淡出、終結聲35ms淡入，保留左右聲道及總混音限制器。
- 音效速率恢復與動畫共用220ms設定。越界落盤衝擊移至動畫0.95秒，極限落盤移至0.55秒，爆裂於1.17／1.21／1.25秒補上零件落地聲。
- 交接時維持音樂壓低，1.45秒後平滑恢復；暫停、離開及靜音會取消終結聲與仍在交叉淡化的撞擊尾音。

## 驗證

- 測試先行驗證同一步決勝、接點過期／重設／減少動態、速率積分及落盤聲時點。加入接盤外緣的完整取景投影檢查。
- 桌機與390×844畫布驗證三種終結，首幀鏡位與注視點完全承接；每80ms檢查至400ms，再檢查落盤終點的逐Mesh／Instance實際頂點投影。定格時鏡頭及模型位置不變，draw不改Battle。
- 專項曾抓到接盤外緣被原全景取景裁切；以FOV計算安全距離修正後重測。舊命中測試由「立即隱藏環」改驗證「物理速度立即恢復、環自然淡出」，符合本版銜接行為。
- 70項Node核心測試與TypeScript／正式Vite建置全部通過，保留既有大型JS檔提示。自然爆裂瀏覽器案例確認實際走到慢速終結交接，四種自然終結的勝者與模擬時長均符合固定輸入。
- 完整回歸中的手機比例量測93幀，中位數16.7ms、p95 16.8ms；混音取樣峰值0.0694，衝擊環幾何UUID不變，draw前後Battle相同。使用原始RAF幀間隔，非截短後的動畫dt；這是本機Chrome量測，不能推定實機效能。
- 45項瀏覽器完整回歸首次44項通過（17.0分鐘）；單人完整流程在原測試截圖時序逾時。調整測試後，完整單／雙人2項重跑全部通過（3.4分鐘），45項獨立案例均已完成驗證。
- 單人完整流程的舊測試在播放中截圖後才暫停，可能錯過2.3秒結算卡片；改為先暫停、在暫停中比較動畫時間及截圖，再恢復，未放寬逾時或修改產品演出。
