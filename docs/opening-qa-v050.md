# v0.5.0 降下開場與旋轉銜接驗收

日期：2026-11-12。基準：`6f19e15e0c62f0f1057bfe009788e723a44fa9bc`（v0.4.0）。

## 行為

- 兩方鎖定發射後建立正式開局狀態，在既有3秒倒數內保持凍結。先懸停，1.8秒開始加速降下，2.45秒落盤、輕彈.2秒並顯示落盤光環；GO後才開始物理模擬，沒有額外等候。
- 降下前後沿用相同落點、發射輸入與種子。開場旋轉使用連續相位，在3秒精確接上初始旋轉角及原角速度；陀螺不會在落地時被重建或換位置。
- 暫停凍結倒數與降下進度；恢復會調整倒數起點並重設上一幀時間。減少動態效果時省略降下、額外傾斜及光環。
- 鏡頭位置與注視點、受撞傾斜改用依時間計算的指數阻尼；30/60/144Hz的收斂一致。懸停高度納入近鏡取景，避免桌機內圈上緣裁切。
- 物理快照重用兩個既有物件；HUD改為100ms更新，進度條使用transform；終結時仍立即更新最終數值。軌跡沿用固定容量緩衝。
- 大畫布依240萬像素預算調整3D解析度，保留小圖鑑與手機的既有比例，DOM文字不受影響。使用setDrawingBufferSize一次更新尺寸與比例；WebGL viewport監測回歸捕捉的縮放高峰由7,629,930降至預算內。

## 界線

降下與輕彈是繪圖動畫，不是新增垂直碰撞物理。效能紀錄只代表本機Chrome及指定測試負載；未驗證實體手機、觸控硬體或實際120/144Hz螢幕。
