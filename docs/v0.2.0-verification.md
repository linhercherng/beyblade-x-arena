驗收使用實際遊戲可發射的65%–100%轉速、三種落點、0–30度傾角。勝率描述此測試分布，玩家自選隊伍、蓄力與難度會改變分布，個別陀螺也各有不同勝率。沒有以40秒硬判勝方或在15秒前鎖住已決勝負。

本輪終結：旋轉15,427、爆裂956、越界0、極限1。四種終結的狀態判定與開口穿越另有測試；此版重視時長穩定，旋轉終結仍明顯多於出界終結。

## 修正依據

- 原版護牆即使只是輕擦也每個tick扣固定0.001轉速，120Hz下放大了持續擦邊的耗損。新測試先重現一秒由95%掉到80.45%，修正為依實際法向速度耗損後通過。
- 原版每次衝刺固定扣1.5%轉速，攻擊型約6次衝刺就多損9%；調整齒軌能量轉換與移動耗損，並縮小類型持久值差距。
- 高轉速時保留較強爆裂與越界穩定性，隨轉速衰減增加重擊效應，降低開局秒殺。勝負仍由物理狀態產生。

## 圖片與模型

- 83個陀螺ID對應83張不同原圖與SHA-256、83組不同72點輪廓。
- 56張BeyGear實際戰刃透明俯視圖，27張Takara Tomy原廠組合俯視圖；逐顆來源與配色範圍見 `product-images.md`。
- 原始圖片未改；卡片、選隊與MVP改用實物圖。3D頂面使用產品貼圖，側面沿每顆輪廓加厚，棘輪與軸心依個別配色／高度呈現。
- 3D側面與厚度是照片分析近似，尚非逐顆CAD或完整零件掃描；戰刃資料庫的配色可能與指定原廠組合不同。
- 內嵌瀏覽器實際查看BX-01及CX-01，確認圖案、輪廓、配色有別，主控台沒有錯誤或警告；修正了canvas固有寬度造成詳細卡右欄過窄的問題。

## 確定性與紀錄

舊發布版物理原文保存為 `physics-v1.ts`，83筆舊數值保存為 `legacy-stats.json`；唯讀複核確認皆與發布版相符。新場次寫入 `engineVersion:2`；沒有版本的舊場次預設1，匯入只接受缺省／1／2。原有戰績與JSON備份保留。

15項Node測試通過，包含8,192場額外保留樣本、83張原圖雜湊、舊版實際紀錄重播、新版固定輸入重播、四種終結、備份與完整賽制。TypeScript嚴格檢查與正式建置通過。

瀏覽器7項完整回歸通過（3.7分鐘），包括83張圖片載入、桌機／手機圖鑑、BX／CX詳細卡、舊版JSON匯入與重播、完整1P／2P、保存重載、備份、暫停及禁用設定儲存。另以約7fps的requestAnimationFrame節奏驗證對決時鐘能在5.5秒內前進至少3秒，該項也通過；合計8項瀏覽器測試。

低幀率追趕視窗由50ms擴至250ms，保留120Hz步長；測試工具移除強制軟體3D與連續追蹤錄影，改用Chrome可用的渲染方式及失敗截圖，避免測試工具本身拖慢遊戲。此為功能測試，仍未代表中階手機實機fps、長時間GPU資源使用或精細側面幾何已驗證。
