# v0.1.0 驗證報告

日期：2026-11-12，Asia/Taipei。

## 已通過

- `npm test`：10 項，含 83 顆資料一致性、固定步長確定性、四種終結條件、每場一次呼喊、搶4分與平手、三級電腦、真實賽事備份往返、雙人戰績與保留上限、損毀備份拒絕、保存輸入逐場重播。
- `npm run build`：TypeScript 嚴格檢查及正式打包成功。JS 約 612 KB、gzip 約 165 KB；Vite 提示單檔超過 500 KB，主因是內含 Three.js，未以隱藏警告代替優化。
- `npm run test:e2e`：4 項完整流程回歸通過，耗時約 2.7 分鐘。使用本機 Google Chrome headless，WebGL 使用軟體渲染，因此不作為硬體 fps 證據。
  - 桌機 1440×1000：83 顆篩選、3D 卡牌、完整 1P 至結算、IndexedDB 重載、逐場重播結果一致、錯誤備份不覆蓋、JSON 匯出與匯入。
  - 手機視窗 390×844：無水平溢出、2P 遮蔽交接、分鍵操作、雙人完整對戰、戰績結算。
  - 發射時暫停不會被空白鍵繞過；模擬主執行緒停止 3.5 秒後仍保留倒數時間。
  - 瀏覽器拒絕 localStorage 讀寫時仍可啟動、切換音效及選隊。
- 額外首屏視覺檢查：桌機／手機截圖與 canvas 正常、手機無水平溢出。
- 另以內嵌瀏覽器實際查看主選單、選隊與發射戰鬥盤，當時主控台無錯誤或警告。
- 程式碼審查發現的暫停鍵盤繞過、長時間暫停時鐘、禁用儲存導致啟動空白三項缺陷，已修正並加入回歸；修正經唯讀複核。

## 物理批次模擬

`npm run balance`：800 場，完整結果保存在 `balance-report.json`。

目前四種終結數量：旋轉 675、爆裂 85、越界 33、極限 7；最短約 1.44 秒、最長約 41.43 秒。攻擊對持久勝率約 80%，攻擊對防禦約 1.3%，持久對防禦優勢過大；部分同類型對決落在 40%–60%。

這些是本版、固定種子和固定輸入測試下的結果，不能推論為真實玩家或實體產品勝率。**尚未達企劃 M5 的整體平衡及所有單場 15–40 秒目標**。沒有用類型倍率或勝負抽籤修飾報告。

## 未驗證／後續

- 中階手機實機 30 fps 與桌機 60 fps 的目標；目前只驗證手機視窗與桌機瀏覽器功能。
- 音效長時間聆聽與不同喇叭／耳機的混音品質。
- 跨瀏覽器同步（不在首版範圍）；不同網址的戰績需透過 JSON 移轉。
- 真實產品數值、重量、幾何及空氣力學（本版全部為遊戲設定）。

原規劃的改裝、線上排行、限定／聯名／復刻機與桌面封裝未加入首版。
