# v0.29.0 碰撞反彈、傾斜與打擊回饋

目的為改善受力辨識及連續動作。延續v0.28.0的模型／碰撞體對齊，不改碰撞半徑、反彈速度、傷害、能力值或隨機流程。反彈路徑由原引擎決定；呈現層補上接觸法線方向的短促傾斜、衰減回彈與回穩。

共用impact.ts從原碰撞衝量、質量與切線速度估計正面程度。相同強度下，正面撞擊有較強傾斜與鏡頭回饋；擦碰降低音量、火花與震動，火花偏向接觸切線。轉速較低的陀螺晃動略大。左右旋使用既有65 rad/s轉速比例與碰撞半徑估計接觸表面的相對速度：同旋的相向刃面剪切較強，反旋且轉速接近時可近似滾動；兩顆依各自旋向進動。這些是遊戲內的視覺估計，並非實物量測。

回彈使用450ms內衰減的連續波形，最多保留8個事件疊加，總傾角限制0.18 rad，避免連續接觸時把舊姿勢瞬間歸零。畫面仍以戰刃中心對齊碰撞體，貼盤高度由既有支撐點求解，不額外推移或抬高陀螺。減少動態設定略過新增回彈；暫停時動作時間不前進，換場及重播重設時清除回饋。

擦碰音使用既有撞擊取樣、較低音高與低通濾波，正面重擊保留瞬態。沿用聲部上限、音樂壓低、靜音及背景中斷機制；濾波隨聲源結束清理。弱左右旋接觸的光環也隨力道降低，避免小擦碰出現大型震波。

測試範圍：法線與玩家交換、左右旋表面剪切、不同轉速、回彈衰減、連續接觸銜接、有界佇列、貼盤、幾何重用、音源與濾波清理、減少動態及戰鬥快照不變；並回歸終結、精彩重播、v1～v5舊戰績與完整66,708場平衡報告。Linux CI只採確定性行為檢查，不以軟體WebGL作實機FPS門檻。

首次瀏覽器斷言把凹碗原有傾斜當成碰撞角度，已改為比較撞擊前後差值；音量測試則等前一重擊聲源結束後，再測擦碰音色。未為這兩項測試修改戰鬥規則。

尚未進行iPhone／Safari實機及耳機主觀聽感驗收。
