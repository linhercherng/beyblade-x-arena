# v0.35.0 材質終結音效

四種終結沿用既有主音，加入金屬、塑膠與橡膠的合成材質紋理，不是實物收音。爆裂在1.17／1.21／1.25秒對齊零件落地，越界0.95秒對齊接盤，極限0.55秒對齊前盤；停轉用既有stopMotion.rock對齊回擺，1.5秒最後接觸，1.65秒收尾，涵蓋原1.6秒側躺動畫。

主音85%與材質紋理18%在同一波形內合成，不新增播放層。既有主音峰值0.82、材質樣本峰值0.59，組合峰值上界0.8032；接觸包絡及尾端淡出仍有限幅。四終結×三材質在啟用音訊時預熱，加上舊五種共17段；勝負音仍沿用原本的按需快取，總鍵數有界。未指定材質的cueSamples輸出保持原樣。

終結依實際落敗陀螺的BeyEffects選材質，沿用原配色與特殊零件濾色。精彩重播的音高及濾波頻寬同乘0.55；一般衝刺命中的慢速交接則在FINISH_RECOVERY=0.22秒一起回原速。配樂退讓直到實際播放長度結束，再平滑恢復；正常速率回復的長度使用duration+(1-initialRate)×FINISH_RECOVERY/2，與finishPlayback積分一致。

原碰撞／衝刺聲先淡出，材質摩擦總線沿用既有退讓，再接終結主音。終結最多一個主聲部與一個15ms替換尾音；再次替換會立即斷開更舊尾音，避免短時間重複觸發累積音源。暫停、靜音、跳過、背景與裝置中斷沿用原清理，silence也清空尾音參照；舊回呼按來源身分刪除。

## 驗證

單元覆蓋44.1／48kHz、四終結三材質的不同紋理、接觸前保留主音、峰值與尾端歸零、停轉後段仍有回擺聲。真實Web Audio專用頁檢查17段快取、所有12種選擇、0.55倍速率及頻寬、40次快速切換的主聲部／尾音上限、正常速率回復、配樂恢復及中斷不補播。另保留既有3D終結本色、衝刺接終結、語音、精彩重播與v1～v5舊戰績回歸。

程式審查的桌面Node預熱測量約234ms、4.43MB，只是該環境的參考，不代表手機啟動成本。沒有新增依賴、控制選項、存檔欄位，未改能力值、物理、隨機數或舊引擎。瀏覽器量測不等於iPhone／Safari、實體耳機與來電硬體驗收。
