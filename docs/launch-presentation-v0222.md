# v0.22.2 開場喊聲與發射演出

基準c30c521。沿用3秒開場、120Hz物理、能力值、種子、計分與舊戰績。未修改任何相依套件鎖定值，僅根專案版本升至0.22.2。

## 語音及聲音

沿用Microsoft David Desktop離線TTS，以SSML強重音、+8%語速與逐拍+1／+2／+3半音製作；Go與Shoot間隔40ms。只裁切頭尾靜音，保留詞間停頓；100Hz高通、2.6kHz加4dB、3:1壓縮及峰值23500/32768，另淡入5ms／淡出15ms。三個數字長0.435／0.320／0.482秒，Go Shoot長0.862秒。數字RMS約為前版兩倍，GO約1.33倍；此為同聲線的重音和音色處理，主觀氣勢仍取決於聆聽環境。

加入120ms節拍與360ms低頻衝擊／風切波形，啟用音訊時預熱兩個buffer、之後重用；數字重音播放率逐拍提高。語音與重音都追蹤來源並可取消，沒有延遲佇列或外部語音服務。

語音每段gain=.52直接進總混音，其他音效／配樂分別經獨立語音優先增益層。起音前8ms將配樂降到10%、其他音效降至32%，維持整句與短尾，再170ms恢復。原碰撞／終結混音無法覆寫這兩層。全域靜音仍由master控制；配樂音量0保留語音。暫停、靜音、離開、背景及裝置中斷取消語音和伴隨音效、還原衰減。

## 畫面

數字文字／環短促脈衝，GO速度線與兩個既有landing ring擴散0.55秒；沒有新增GPU網格或動態粒子。GO文字保留到1.1模擬秒，物理照常推進。裝飾無文字且aria-hidden，不增加倒數的重複宣告。沿用battle-message暫停動畫與Arena時間，暫停時凍結；減少動態時不顯示環和速度線，仍保留語音與靜態GO。

## 驗收

先確認核心缺少重音函式及三項瀏覽器新行為測試失敗，再實作。初步8項倒數／語音／混音／動效測試通過；兩項視覺測試再次通過，截圖為暫停後移除遮罩、將動畫固定90ms的畫面檢視，不代替自然播放的操作斷言。

最大配樂加30強度重擊的Chrome測試，在語音最強的取樣窗口量得voice RMS .1181、music .00285、其他SFX .0266，master最高峰值.2579；單一窗口不代表整句所有音節的比例。測試要求voice分別大於music兩倍、SFX1.2倍，整句期間voice duck保持.1／.32，之後恢復大於.97。每次CI保留這些測試與原完整66,708場平衡；沒有放寬門檻。

目前沒有iPhone實機；Windows WebKit僅驗證操作與減少動態，沒有AudioContext。瀏覽器音訊圖量測不等同於實際喇叭、耳機的音色／音量驗收。


收尾：119項核心與正式建置通過，20項既有音訊／來電／裝置切換／開場／暫停GPU／重播混音回歸通過；WebKit六項UI／動效回歸通過。混音測試另外觀察完整語句，起音25ms後至自然結束的最大語音優先增益仍維持music .1、SFX .32。獨立程式複查無阻擋問題。完整CI、平衡報告與匿名公開站會核對最終提交。


首次CI有11項通過；新混音案例的所有聲音斷言亦通過，但寫出量測JSON時因artifacts尚不存在而失敗，當時未部署。已補上建立輸出目錄，並在新的空工作目錄中單獨執行該案例，測試與輸出檔都成功；遊戲程式未因這項修正改動。最終CI會重新完整執行。


## v0.22.3 公開驗收收尾

v0.22.2匿名公開站六項中有五項通過，單人案例記錄Three的stop呼叫；該次沒有記錄時間，因此不足判斷是否截斷。原測試將任何stop呼叫均視為截斷，未區分已播完的清理。現改用原生AudioContext排定停止時間與buffer自然終點比較，保留記錄；三次公開CPU重測未觀察到提前停止。另加入ended回呼延遲的故障注入，確認下一拍不受舊清理影響、無重播或重建快取。

追加驗收發現實際問題：喊聲中暫停時，語音duck在40ms恢復、原配樂仍需180ms淡出，造成短暫音量回升。新測試先失敗，量得配樂總增益從.01326短暫升至.02265；修正後最高仍為.01326。取消語音時，duck保持至180ms配樂淡出結束，再以music .06／SFX .18秒時間常數恢復；自然喊完的原排程不變，新一拍會取消舊排程並立即起音。此修正不改物理或平衡。


v0.22.3本機收尾：119項核心與正式建置、22項瀏覽器回歸全部通過；延遲ended故障注入確認舊清理不會抹除新一拍，四段PCM快取仍保持4個。補正後暫停包絡before／after皆.01326。追加程式複查無阻擋項目，最終CI與公開站另以相同提交核對。
