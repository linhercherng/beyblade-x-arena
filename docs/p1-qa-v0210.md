# v0.21.0 P1：狀態、雙人操作、平衡回歸與勝負說明

本輪不改物理引擎5、特性版本1、能力值、種子、計分及備份格式。舊版1–4仍依各自凍結引擎重播；新版分析只讀原來保存的紀錄。

## 音訊恢復

上方單一狀態區顯示等待操作、恢復中、尚未恢復、通話中斷或配樂載入失敗；正常與全域靜音時收起。配樂設定內保留完整狀態文字。沒有聲音播放能力時仍可遊玩，關閉的AudioContext提示重新載入。瀏覽器狀態正常只表示程式可送出音訊，不保證耳機實際有聲。

狀態每200ms從現有RAF讀取，只有狀態改變才更新文字，不新增通知計時器或每幀重複宣告。通話中及恢復中的重試按鈕停用；resume拒絕或1.5秒仍未完成即可重試，不讓未完成Promise永久鎖住按鈕。使用者明確重試才解除配樂下載失敗快取；保留原音量與靜音偏好，中斷後不補播舊音效。Space／Enter聚焦重試時保留原生按鈕行為，不觸發發射或呼喊。

## 手機雙人操作

1P固定左、2P固定右，各自有滑桿、±1°微調、落點、傾斜方向及鎖定。沿用既有TouchEvent identifier／PointerEvent捕捉與去重，微調走同一個有暫停、鎖定及畫面檢查的setter；調整單方不重建另一方的控制區。0°／30°停用超出範圍的微調。

按鈕及滑桿至少44px高；320px時落點與方向換成兩欄再跨欄，維持至少44px寬。700px以下發射頁先顯示兩人操作，再顯示盤面預覽；開場及正式戰鬥維持原來的大盤面。701–1100px且高度不超過500px時收緊說明與間距，不縮小觸控目標。橫直向、暫停、背景及取消手勢沿用既有清理，恢復後需重新觸碰。

## 勝負原因

回合結果直接顯示實際終結判定；回合、結算及戰績可展開逐場比較。力量、傾角、落點、內外切、總衝量、最大衝量、衝刺次數、剩餘轉速均讀自保存的Round。缺項標示「未記錄」，報告ID必須與該場陀螺相符；沒有用目前能力值回算舊資料。終結條件說明與各項數據分開，沒有虛構運氣或各因素勝率貢獻。

## 平衡自動回歸

每次GitHub push及PR執行核心測試、完整平衡模擬與正式建置，報告作為artifact保留14天。沒有增加定時排程或改分支保護。

`npm run balance:check`與原本`npm run balance`使用相同種子、樣本及判定門檻，改把報告寫到忽略的`artifacts/balance-check.json`，不覆寫版本化報告。檢查使用未四捨五入的勝場／出戰數；14.43秒即使outsideTarget誤為0也會失敗。四類型需有樣本、勝率40–60%；每組最短／最長皆須15–40秒且無越界計數。校準與驗收另檢查停轉不超過50%、爆裂與越界各至少10%、極限至少5%、平手不超過5%。

## 驗證範圍

核心測試包含音訊狀態分支、平衡門檻失敗案例、舊版1–4與新版5的保存數據只讀檢查。瀏覽器新增雙點同時微調、持續拖曳時另一指微調／鎖定、窄畫面觸控尺寸、音訊中斷／逾時／拒絕提示、相同狀態無重複文字更新及配樂失敗後鍵盤重試。音訊中斷與Promise異常由故障注入測試；Chrome音訊圖為原生。WebKit單點使用原生tap，多點使用合成TouchEvent容錯測試。

目前沒有iPhone可測。藍牙、耳機拔插、來電、鎖屏後實際聽感、熱度及長時間手機幀率仍未驗收；保留P0裝置檢查／匯出流程，人工項目維持未測試。未改3D渲染，不重跑前版15分鐘合成壓測；前版結果不得視為本輪iPhone驗收。
