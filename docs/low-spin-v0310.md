# v0.31.0 低轉速、失衡與停轉演出

原本spinLean只依tilt產生固定幅度進動，停轉後另以世界Z軸線性翻倒，並用包圍盒抬升模型。低轉速的衰弱程度不明顯，側躺方向也未接續當下傾斜，斜坡上的包圍盒保護可能使實際模型浮起。

現在轉速低於0.32時逐漸增加失衡幅度，仍沿原物理旋轉相位進動，沒有獨立高頻計時抖動。保留預設spinLean呼叫行為；戰鬥渲染傳入實際插值轉速，接續既有斜坡姿態平滑與受撞回彈。

停轉首次繪圖擷取目前姿態與上一畫格轉速，沿當下傾斜方向側倒；若尚無明顯傾斜則選擇斜坡下行切線。1.2秒內平滑側倒，餘轉沿各自旋向減速，接著輕微摩擦回擺，1.6秒後完全靜止。這是遊戲演出參數，不代表實物摩擦係數或慣量量測。低轉速勝者的慶祝餘轉也受原轉速限制，避免突然加速。

BowlContact.rest共用既有幾何快取及支撐點求解，按實際側躺姿態重新計算高度與戰刃中心位置，取消停轉路徑的包圍盒抬升，不拆動三段零件。保護間隙為0.004場景單位。停轉不再合成碰撞火花；停轉音效及比分規則沿用原流程。停轉光環錨定原對戰中心，避免側躺原點偏移使光環漂移。

暫停固定動作時間；重播尾端定位、換場與新終結清除舊停止狀態。減少動態直接呈現貼盤靜止姿態。物理引擎、碰撞與摩擦計算、能力值、隨機數及存檔格式均未變更，舊戰績仍由原引擎重播。

驗證包含91款模型在中心與兩段斜坡的側躺間隙、旋向與自轉相位、低速幅度連續性、側倒起步銜接、餘轉與回擺有限時間收束、左右旋／中心／斜坡實際繪製、長畫格、暫停、尾端定位、減少動態及零件／幾何重用；另回歸既有碰撞、齒軌、終結、精彩重播、v1～v5戰績與66,708場平衡報告。
