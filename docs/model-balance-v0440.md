# v0.44.0 型號平衡追查

## 結論與範圍

原觀測每款728次出戰，11個旗標並非失衡判決。型號等量使攻擊／平衡型對手較多，四組發射也包含位置與傾角差異。新增配對對照後，原11款在兩批不同種子下，原始與四類等權勝率皆同方向偏離：10款偏弱、皓戰猛虎偏強；對手組成只能解釋部分差距。結論限列明遊戲情境，不推論實物或所有玩家操作。

全91款掃描另發現天馬九尾・重裝：第一候選的原型號等量結果39.286%，四類等權40.823%；額外配對實驗顯示原v5本來已偏弱（兩批原始35.799%／36.181%、等權38.608%／38.624%），第一候選對手池下差距更大（32.708%／33.125%、等權約35.28%）。因此也依同一確認標準校準，不把影響轉移給未檢查的型號。

最終只調12款的耐力（STA）：原11款值保持鎖定，新增天馬九尾72→80。其餘79款，以及所有型號的攻擊、防禦、衝刺、爆裂耐性、重量、零件、旋向與外觀皆不改。未改運動、碰撞、計分、亂數、開場保護、末段耗轉或終結門檻。

## 實驗與判定

- 每款對其他全部90款，排除同型號鏡像重複；四發射情境、各四個種子，同種子／同輸入互換玩家側，共2,880場。原始勝率按型號等量，另列四類各25%等權，平手均留在分母。
- 校準A為0x3782a4c1，保留驗收B為0xb719d263。先用兩批舊版確認方向；調值只使用A，固定候選後再跑新版B。新增型號只在A測STA+8／+10／+12，選最小合格測試候選+8，沒有依新版B繼續調整。
- 四組為雙方65%／0°／中圈／沿旋、100%／15°／外圈／內切、85%／30°／內圈／外切，以及獨立隨機力量／傾角／落點／方向；編號1、3在同一tick同時呼喊。
- 全v5及完整新版本各跑A、B；另跑A的逐款隔離對照：只有目標使用新版STA，全部對手固定v5能力。合計172,800場，保存實際目標／對手能力、種子、兩側、情境、配對、平手及勝負終結。
- 門檻要求舊版A／B兩種權重同向越界、調值方向相符；隔離必須同種子／樣本／對手，只有自身STA不同，且改善確認方向。新版A／B的兩種權重均須40–60%，全場15–40秒。
- 配對兩側不視為獨立樣本；以固定情境的不同種子重現及控制變數辨識，不宣稱普遍統計保證，也不把不同發射分布當同一母體。

## 為何只調耐力

原能力由輪廓／軸心估值推導；防禦型STA幾乎同為72，但幾何慣量仍影響同能量下的初始轉速，移動驅動也會耗轉。部分型號在對稱發射下較早停轉，偏弱型號的敗場多為停轉；皓戰猛虎則在較低慣量與巡航條件下維持較高勝率。

先以固定對手對五款代表做STA單變數掃描，再用A決定候選，全部12款均補隔離對照。這是遊戲數值校準，不改原廠零件標示，不把估值當實測。STA只透過原耗轉公式作用，沒有直接指定輸贏。

## 重播相容性

最終新對戰標示引擎v7、特性v1。v5使用91款原能力；先前v6試跑候選的91款能力也另存快照，避免補校準影響已產生的v6紀錄。v1～v4保留原分流，不遷移／覆寫既有戰績。

48組v5案例以36912ed的實際物理來源與原能力生成，保存6秒／12秒位置、速度、轉速、傾斜等及最終結果，逐值比較JSON可表示的數值；原v6 fixture保持不變，另驗證v1～v7備份、跳轉及瀏覽器重播。
