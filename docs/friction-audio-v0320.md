# v0.32.0 低速摩擦與停轉音效

Arena從實際繪圖姿態、盤面法線、插值轉速與自轉相位產生雙方FrictionFrame。停轉使用與側倒動畫相同的finishElapsed與stopMotion，低速擦盤隨進動及接觸傾斜改變強度，側倒與回擺逐漸收束，1.6秒後靜音；減少動態直接採靜止相位。

Sound.update新增可省略的第5參數，由正式遊戲傳入當幀資料；原呼叫方式保持可用。摩擦樣本啟用音訊時合成及快取，循環接縫使用20ms交叉混合；每位玩家最多一個持續聲源，調整音量、速率、低通與聲道，不逐幀重新播放。金屬軸較明亮、橡膠較低沉，仍經原SFX與語音優先增益。

音量上限0.25、循環波形峰值0.6，音量變更使用25ms淡化，音高與聲道也平滑調整。停止先標記closing，再淡出及停止，ended前不另建相同玩家聲源；回呼按身分清理，避免舊回呼刪除新聲源。背景／裝置中斷由既有silence流程立即斷開並清空節點，恢復後只按當前畫面重建，沿用原主音量淡入。

最大配樂音量實測顯示原摩擦層偏弱，因此提高樣本層的可聽度並保持0.25上限。配樂依實際摩擦目標音量按1/(1+20×level)退讓，80ms柔化進入、180ms恢復，只有混音比例有明顯變化才更新排程；音量滑桿保留原偏好，摩擦結束回到原配樂音量。語音與碰撞優先增益仍沿用原流程。

暫停、靜音、離開對戰與重播定格關閉摩擦；恢復不補播舊瞬態，精彩重播依既有慢放比例降調。跳轉尾端時已是靜止相位，不重新擦盤；新場景的畫面資料也會重設。沒有新增音量控制或存檔欄位，物理、勝負、隨機數、能力值及舊引擎保持原樣。

驗證包括44.1／48kHz波形與循環接縫、低速／側倒／回擺同相位、音量及速率上限、重用聲源、快速暫停與靜音、尾端定位、定格與慢放、背景與輸出裝置中斷、恢復增益、原語音播報及音樂流程；另回歸v1～v5戰績與66,708場平衡報告。瀏覽器量測與故障注入不等於iPhone、藍牙耳機或來電實機驗收。
