# v0.36.0 終結、播報與結算配樂交接

碰撞、齒軌衝刺及終結共用原有 musicDuck 節點，保留重疊事件最深退讓及最晚恢復時間。原本後來的短碰撞會取消終結的長退讓，測試中500ms後配樂已回到0.93；現在會等終結實際播放長度結束。一般終結目標0.25，精彩重播0.12，以減少配樂對既有金屬、塑膠及橡膠接盤紋理的遮蔽，不增加聲部或改變原音效快取。

播報仍獨立通往主輸出，配樂／音效優先增益維持0.1／0.32。退讓涵蓋實際 startAt+片段長度，再留60ms；以120ms／180ms時間常數回升，取代原170ms內直線恢復。取消時沿用180ms保護交叉淡出，避免跳過、暫停與下一段開始時突然掀起音量。

舊播報先淡出15ms，下一次替換立即斷開更舊尾音，讓終結／勝負語音最多一個主聲部與一個尾音。開場語音另有原本的發射 accent，兩者一併清理。ended回呼依來源身分清除；背景與裝置中斷也清空尾音參照，不補播。精彩重播沿用既有不重複喊聲規則。

新增真實 Web Audio 回歸：慢放終結後再擦撞及調整最大配樂音量，退讓仍維持至尾音結束；40次快速切換播報從原40個聲源降至最多2個；語音結束後檢查平滑釋放窗口，並驗證下一次播報與取消恢復；三種材質終結搭配最大結算配樂，量測語音相對配樂及音效的RMS、主輸出峰值。觀察釋放窗口以原生ended事件對齊，避免預設輪詢跨過短窗口。

沿用既有材質波形、慢放頻寬與音高、音訊生命週期、舊引擎及v1～v5戰績重播檢查。沒有新增依賴、逐幀混音工作、存檔欄位或遊戲設定，未改物理、能力值或隨機數。合成材質音色與瀏覽器量測不等於實體iPhone／Safari、耳機切換或來電硬體驗收。
