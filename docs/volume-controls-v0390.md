# v0.39.0 音量與靜音銜接

配樂音量歸零或靜音後，原曲目會淡出180ms。若在此期間恢復音量，原本的增益回升也會作用在退役曲目上，使尾音再被帶出。新回歸在原碼重現兩項失敗：快速歸零／恢復，以及靜音／重開後，舊曲在100ms內仍未結束。

setMusicVolume、取消靜音與原本的換場／摩擦增益共用setMusicGain。先cancelAndHold保留當前值並取消舊排程；重新開啟時，已退役曲目以15ms淡出並提早stop，共用配樂增益先短暫降低，20ms後才恢復。後續滑桿或換場仍遵守同一截止時間，避免新設定提早掀起舊尾音。原本等待尾音ended、revision及ready檢查保留，所以新曲仍按最新模式啟動，不增加疊播聲源。

只處理music增益；主音量、語音與音效的起音時序不變，配樂歸零仍能播放新語音。沒有新增音檔、聲源、AudioContext或設定項目。保留原音量範圍、menu／battle相對音量、frictionMix、語音優先退讓及靜音清理。silence會清除短暫重開截止時間，過期背景請求不會重啟舊曲。

音量及靜音沿用原localStorage鍵與例外處理。新增五項真實Web Audio／實際UI檢查：兩種快速重開、60次調整及同時換場以最後值為準、配樂歸零仍有新語音且不補播、35%與靜音跨單人／雙人／選隊／重新載入保持一致。原碼2項失敗、3項通過；修正後5項通過。另保留既有音訊生命週期、路由恢復、倒數、精彩重播及v1～v5舊戰績回歸。

第一次混合執行遇到一項既有冷啟動clock-stalled：發生在首次RMS等待，尚未操作滑桿或靜音。審查確認未進入新重開分支時，初始化與原排程等價；該項與新控制測試單獨6項重驗通過。保留原時鐘停滯偵測與手動恢復，不放寬斷言；完整回歸另行驗證。

未更改物理、能力值、隨機數、引擎或戰績格式。瀏覽器與注入路由事件不等於實體iPhone／Safari、藍牙耳機或來電驗收。
