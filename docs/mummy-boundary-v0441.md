# v0.44.1 古屍詛咒邊界勝率追查

## 結論與決定

古屍詛咒（ux-18-mummy-curse）保留原有全部能力，含STA 72；全91款數值、發射、移動、碰撞、終結、亂數及時長公式皆不改，新對戰仍用引擎v7，既有v1～v7重播分流與快照不變。

原觀測39.973%不能解讀成普遍失衡，也不能把所有偏差都歸為樣本波動。本輪三批新樣本顯示：

- 原觀測形式的新配對結果44.219%～45.747%，沒有重現原旗標。
- 加入低力量0.4的等條件格，型號等量38.576%～39.068%，四類等權41.046%～41.467%。組成敏感性跨批重現，並非只差一勝的問題。
- 現行操作蓄力下限為0.65（src/main.ts的chargePower）；等條件格中0.65／0.85／1的描述性子集為40.386%～40.818%，四類等權42.974%～43.336%。0.4是引擎仍接受的歷史／壓力情境，沒有刪除這些不利結果。
- 對平衡型與低力量、大傾角的弱勢持續存在；對持久型則有優勢。不宜以全域增加耐力消除單一加權旗標，否則也會強化本來已占優勢的對局。

依看結果前固定的標準，三批主分析的兩種權重區間沒有同時、同向完全越過40%或60%，因此判定 **not-confirmed（未確認持續失衡）**，本輪不調值。這不是證明每個條件或每種對手勝率都在40%～60%。

## 固定設計與樣本

計畫先於新結果記錄於 [實驗計畫](plans/2026-11-21-mummy-boundary.md)。三批種子為0x52691db3、0xd04ba827、0x91e3c65d；每款對其他全部90款，排除鏡像。每個情境8個種子，每個種子及輸入互換玩家側。

每批16情境：4組原觀測形式與12組等條件格，兩組分開統計，不混成單一總勝率。原觀測形式含雙方0.4、0.65對1、雙方1、獨立0.4～1；固定傾角／落點及異力量的輸入角色在八次重複中各占四次，呼喊亦一起交換，避免弱發射永遠給目標。呼喊沿用720／840 tick（6／7秒）。等條件格為雙方同力量0.4／0.65／0.85／1 × 同傾角0／15／30度；落點、方向獨立抽取，6秒同時呼喊。

兩個對手池逐種子對照：現有v7能力，以及固定v5對手能力；目標在兩池均保持現有v7能力，不把舊版目標能力偷偷代入。共138,240場，其中現有對手69,120場，舊對手控制69,120場。共34,560個新種子；兩側合成一個配對樣本，兩池是控制對照而非新增獨立樣本。新種子與既有model、allPairs、runSuite及runEdges集合無交集。

原始勝率按90款等量；四類等權令攻擊／防禦／持久／平衡各25%，平手保留在分母。95%配對Hoeffding區間使用每個種子兩側勝率的平均值，取值範圍[0,1]；類型加權以各配對權重平方和計算界限。區間以獨立種子為假設，限這個固定遊戲情境集合，不推論實物或所有玩家行為。確認需三批現有對手的完整12格主分析，原始與等權區間都完全低於40%或高於60%，且三批同向。單格、單類對手或偏重組成不單獨觸發調值；目前蓄力子集僅作補充分層，不更改預定判定。

90款對手包含攻擊28、防禦19、持久18、平衡25。型號等量自然讓攻擊與平衡占比超過25%，而這兩類正是本款相對不利的對手。

| 對手類型 | 等條件三批勝率範圍 |
|---|---:|

| 防禦 | 48.958%～49.836% |
| 持久 | 62.095%～63.252% |
| 平衡 | 17.458%～18.354% |

將同一條件資料重新加權成某類占50%、另外三類各1/6，結果為攻擊偏重38.847%～39.413%、防禦偏重43.910%～43.976%、持久偏重48.178%～48.729%、平衡偏重33.184%～33.763%。這是對手分布的敏感度分析，不是額外模擬場次。

固定全部v5對手、目標仍用現有能力時，等條件型號等量42.373%～43.137%，四類等權45.272%～45.994%；同種子改回現有對手後，分別降低3.796～4.265及4.226～4.774個百分點。對手校準確實影響此款對局，不能說差異全是隨機。影響主要見於對防禦型勝率：舊對手64.419%～66.064%，現有對手48.958%～49.836%；對持久型則沒有改變。因此未發現足以支持一律加強本款的跨組成證據。

## 回歸與可重現性

`npm run balance:mummy`輸出研究完成／失敗與判斷，不等同整體發布通過。`npm run balance:check`在原66,708場及12款172,800場驗收之後，再跑本輪138,240場，共377,748場；新增發布護欄：研究未完成、缺樣本或確認失衡但未校準時均阻擋。原類型40%～60%、全場15～40秒及終結比例門檻沒有放寬。

產物為artifacts/mummy-boundary.json、.md與mummy-boundary-pairs.jsonl，含來源SHA／未提交狀態、實際對手與目標能力、每種子輸入、呼喊、兩側／兩池結果、秒數與分層統計；CI四分片皆保存。每次執行先寫running，失敗寫failed，避免沿用舊通過結果。開發試跑證據另留於artifacts/mummy-v0441，不當成乾淨來源的正式驗收。正式發布須以相同已提交來源完成核心、221項瀏覽器、完整平衡與建置，並通過四分片合併及公開站檢查。
