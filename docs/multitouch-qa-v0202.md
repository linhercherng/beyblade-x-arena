# v0.20.2 手機雙人多點觸控

2026-11-14。保留1P左、2P右配置，物理引擎5、個體數值與戰績格式不改。

## 行為

- 雙人方向改為三個直接選擇按鈕，避免原生選單占用整個畫面；單人模式保留選單。
- 每根角度拖曳指標固定綁定原玩家，捕捉拖曳後跨過中線也不串位；同一玩家已有角度手勢時，另指不搶走滑桿。
- 兩人可同時調整、按下鎖定與呼喊，包含非主觸點。鎖定在按下時讀取各自蓄力，沿用原力量公式；只停用該玩家控制，不重建整個面板。
- 按鈕沿用原計分與事件邏輯；阻擋後續實體click重複啟動，保留detail=0的鍵盤／輔助操作路徑。聚焦玩家按鈕時，Space／Enter只啟動該按鈕。
- 抬手、取消、遺失捕捉、暫停、切換畫面或視窗失焦會清理對應手勢。局部取消不清除另一方手勢；暫停恢復後需重新碰觸才會繼續拖曳。
- 角度輸入停用原生TouchEvent拖曳，統一由指標控制。否則原生range可能在暫停後自行改動畫面值；這個重現案例已補測。禁止縮放／選字只作用於雙人控制元件，其他區域保留原滾動行為。

## 驗證

`tests/e2e/multitouch.spec.ts` 使用Chrome DevTools Protocol的 `Input.dispatchTouchEvent`，送入同時存在、具有不同ID的原生觸點；沒有用兩次滑鼠點擊冒充多點觸控。

- 原版同時鎖定及一方鎖定／另一方拖曳兩案例均失敗，修正後通過。
- 6項手勢／鍵盤專項全部通過，覆蓋雙方同時拖角度／選方向／選落點／鎖定／呼喊、跨中線、取消、暫停恢復、保持雙滑桿時另指點方向、同玩家競爭觸點及聚焦2P按鈕的鍵盤行為。
- 既有13項回歸通過：完整單人與手機雙人賽事、備份／重播、暫停、五尺寸左右配置、一鍵開局、降下與倒數。五尺寸為320／390／844橫向／1280／1440像素。
- 既有88項核心測試通過；TypeScript／Vite正式建置通過。獨立唯讀審查未發現重要缺陷；追加原生range處理亦經複查。
- 截圖、執行日誌與公開端匿名多觸點檢查回執留在忽略的 `artifacts/`；未在正式使用者瀏覽器寫入測試戰績。

尚未測試手機實機、Safari／VoiceOver及實體多點觸控硬體；Chrome多觸點模擬不等同這些裝置的驗收。本次未重跑平衡批次，物理與能力檔案未變。
