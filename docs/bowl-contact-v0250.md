# v0.25.0 凹碗貼盤與齒軌接觸

固定墊高 0.065 會讓軸尖浮在新版凹碗上；固定 3.84 咬合半徑也無法配合各款軸心齒輪。新版由實際模型頂點（包含實例化齒輪）預先建立凸包，每幀只轉換最多約335個支撐點，計算貼盤高度與坡面法線。斜坡傾斜與既有搖晃、發射傾角、連續自轉合成；坡面方向平順過渡，暫停保持不動，重播定位重新取得法線。開場降下仍保留獨立高度。

咬合以各款齒輪實際外緣接近半徑4.13的齒面，配合向外傾斜及25毫秒入軌過渡，避免瞬移。保留原自轉相位；三個出口不顯示虛構咬合，減少動態模式仍停用貼軌位移。落盤與結算光環順著坡面法線放置；停轉側躺保留坡面姿態，再按既有方式避免穿盤。

只更動呈現，未改物理力、x/z運動、碰撞、抓軌判定、隨機種子、陀螺能力、勝負規則、儲存格式或舊重播引擎。視覺貼軌位置不回寫 Battle。

驗證：91款模型於中心、內坡及外坡，跨多個自轉相位與傾斜角，實際頂點無穿盤且最低點距盤面小於0.013；齒輪接觸高度0.459～0.520，位於齒面0.43～0.532內。瀏覽器對實際盤面Raycast驗證貼合，另涵蓋咬合、暫停、出口、減少動態、爆裂／越界／極限／停轉、手機尺寸及既有重播。核心回歸與建置、平衡報告及公開產物核對隨發布保存。CI新增實際齒軌接觸檢查。

效能採模型建立時快取，沒有增加每幀幾何／材質建立、陰影燈或後製。桌面Chrome與390×844手機尺寸檢查不等於iPhone/Safari實機效能驗收。

完整平衡66,708場，報告與v0.24.0逐項完全相同；各類型勝率維持40%～60%，所有驗收場次15～32.867秒（上限40秒）。132項核心測試與正式建置通過；獨立唯讀複查無阻擋問題。
