# 引擎5：發射、逐顆特性與可重播運氣

2026-11-13，依使用者已確認方案實作，不另設確認關卡。

## 目標與順序

1. 凍結v4演算法與全部91顆原能力，保留v1–v4紀錄回放；儲存驗證接受v5，不更動既有備份版本。
2. 以方向傾斜、發射能量、落點建立初始狀態；移除依時間正弦波指定目標半徑的導向，改由碗面、摩擦及軸心驅動形成路徑。
3. 依已保存的逐顆照片輪廓／厚度、零件結構建立明確特性表，取代v5的名稱雜湊差異。所有參數是遊戲估值，不冒稱實測公克、慣量或摩擦係數。
4. 種子固定發射效率±3%、方向±2度、摩擦±2%；對稱、與比分無關，不抽籤決勝。衝刺與軸心驅動從旋轉能量支付額外移動能量。
5. UI顯示發射方向、角度影響及特性來源；保留既有呈現與效能預算。

## 驗收

- 單元：發射力量／角度／落點影響、有限能量、參數有限、固定種子一致／異種子可變、換邊公平、v4逐步結果完全一致與備份相容。
- 平衡：先快速探索，後使用獨立種子、交換玩家側的四類型等量樣本，勝率40–60%；邊界與全91×91配對皆15–40秒。保留終結分布與四類型特色門檻。
- 正式TypeScript/Vite建置、相關瀏覽器及完整回歸；舊版回放、發射、暫停、精彩重播與公開匿名開局。
- 命令：npm test；npm run build；npm run balance；node --experimental-strip-types scripts/expansion-balance.ts；npx playwright test --reporter=line。

## 邊界

不新增依賴、不重建模型、不移除舊戰績、不用固定勝率或終結抽籤代替模擬。15秒開場保護與30秒後疲勞仍作明示的遊戲節奏規則，並非實物物理保證。GitHub main及現有公開Sites在全部檢查通過後同步更新。
