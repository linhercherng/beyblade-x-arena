# v0.18.0 隨機雙方立即對戰

日期：2026-11-13。新增主畫面快捷入口，保留原有組隊與發射流程。

## 行為

- 主畫面「組建隊伍」下方新增「隨機雙方・立即對戰」，沿用目前單人／雙人模式及電腦難度。WebGL無法啟用時與原開局按鈕一樣停用。
- 雙方各自從完整圖鑑抽三顆不同戰刃，兩隊之間允許相同型號。沿用v0.17.1的randomTeam；單人CPU隊伍也純隨機，不經一般選隊的相性反制。
- 一鍵略過選隊、雙人交接、公開確認與手動鎖定，直接進入既有3秒倒數及降下動畫。1P預設90%蓄力、中間落點、10度傾角；雙人雙方設定相同，單人CPU發射仍依所選難度產生。播放速度重設1倍。
- 共用原createMatch、prepareRound與從lock抽出的startCountdown，沿用原倒數時鐘、物理版本4、正式計分及戰績。暫停精確凍結；下一場仍回原發射準備，可手動調整。
- 快捷操作只在主畫面有效；原本的快速組隊、隨機單隊與手動選隊入口保留。

## 驗證

- 新增兩項瀏覽器測試，舊版因不存在快捷按鈕而失敗，再實作功能。桌機單人選高級與手機比例雙人，皆檢查直接進倒數、雙方共六個出場位置、CPU／2P標示、暫停、無需鎖定即可開戰、首場結算與下一場原發射控制。
- 80項核心測試通過，包含原8,192場對稱保留樣本40–60%類型勝率與15–40秒模擬時長；未修改物理、能力、計分及儲存程式。
- 11項相關瀏覽器案例通過（1.6分鐘），涵蓋新快捷、原隨機單隊、倒數只更新一次、GO暫停、低幀率計時、開場降下與減少動態。另重跑2項快捷流程通過（36.7秒），並確認手機截圖能看到按鈕；截圖存於忽略的artifacts/quick-battle-*-v0180.png。
- TypeScript及正式Vite建置通過；保留既有大型JavaScript分塊提示。唯讀程式碼審查未發現重要缺陷。
- 保留原本RAF時鐘基準後，最後7項快捷／倒數／開場回歸再次全數通過（1.2分鐘），正式建置再次通過。

本輪未重跑完整60項瀏覽器套件、62,340場完整平衡或實體手機驗收。瀏覽器結果為本機Chrome；正式發布結果另存忽略的artifacts/deployment-v0180.json。
