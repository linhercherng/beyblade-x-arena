# v0.17.1 計時提示與隨機選陀螺

日期：2026-11-13。使用者確認反覆提醒來自秒數／「開場穩定期」文字。

## 修正與選隊

- 計時區原先每約100ms重寫相同階段文字。改成秒數或階段文字真的改變才寫入；計時區使用timer語意並明確設為aria-live=off，保留畫面時鐘而不反覆即時播報。
- 另重現開場3由renderArena與第一個RAF連續寫入兩次。改由既有倒數迴圈統一顯示，每個數字一次；原倒數與降下時間不變。
- GO原先使用850ms的setTimeout，即使暫停仍清除。改依正式對決經過時間清除，暫停／繼續與速度倍率一致；只移除GO節點，不會誤清衝刺或終結訊息，也沒有跨場延遲回呼。
- 隊伍編成的「出場順序」下方新增「隨機選陀螺」。從完整91顆圖鑑抽三顆不同戰刃，替換目前玩家整隊；可重抽、刪除及調整出場順序。單人及雙人兩位玩家皆可用，雙人交接仍隱藏前一位隊伍。原「快速組隊」互補預設保留。
- 抽選使用新種子和既有rng，只操作圖鑑副本；不受搜尋／類型篩選限制。沒有修改CPU策略、能力、物理、計分或戰績格式。
