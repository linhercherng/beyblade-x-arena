# v0.6.0 競技盤與配樂驗收

日期：2026-11-12。基準：`9e762353872a60536094ef45f22d8f81b71db9e0`（v0.5.0）。

## 結果

白色塑膠競技盤補上碗面刻線、藍色細齒軌、透明護欄、支柱螺絲、底殼肋、光條及三個斜坡接盤。盤面高度與出口淨空保持目前物理場地；手機全場鏡頭增加取景餘量，近鏡及開場維持原有行為。盤體為原創造型，不是原廠盤CAD。

新增四首原創配樂，選單／交戰／賽末點／結算分別使用不同編曲。交叉淡化.5秒，暫停.18秒淡出並保留播放位置；交戰／賽末點同BPM同調及8小節和聲，按播放相位銜接。音量調至0只關配樂，既有「音效 關」全部靜音，均保留使用者設定。首次操作才建立AudioContext，不會未經操作自動出聲。

音效經.27增益、配樂預設.6，進入.65總音量與動態限制器，保留碰撞音效空間。解碼音訊快取限制兩首，離開的source停止後解除節點連接。單曲失敗不重複載入、不影響其他曲目與遊戲；晚到的載入有場景版本檢查。

## 驗證

- 單元測試：36項，包含盤面射線、合法出口全半徑淨空、有限幾何、45個盤體物件上限、配樂路由／音量、原有規則、平衡、備份、兩代引擎及旋轉／開場。
- 瀏覽器音訊：實際AudioContext解碼與播放四首MP3，以Analyser確認非靜音；音量0、全域靜音及暫停訊號歸零，恢復保留播放位置；延遲下載在暫停後不會出聲；儲存禁用可用；404只請求一次，其他曲目仍可播放。
- 實際介面：配樂音量重新載入仍保存，發射畫面用鍵盤Space展開配樂不觸發發射；停止rAF後觸發hidden仍立即停止音訊，避免背景分頁持續播放。
- 已查看桌機1440×1000及手機390×844的未暫停對戰截圖，手機全場三個接盤與配樂面板都在畫面內，無水平溢出。本機圖檔：`artifacts/stadium-v060-battle.png`及`stadium-v060-battle-mobile.png`。
- 最終 `npx playwright test --reporter=line`：19項全部通過（4.1分鐘），涵蓋上述音訊與介面、1P／2P完整對戰、備份／舊版重播、低速旋轉、畫布預算、開場／暫停／減少動態。`npm run build`通過；既有單一JavaScript chunk大小提示仍存在。
- 審查發現背景rAF停止時配樂可能續播，已改在visibilitychange直接淡出並取消待播；配樂設定鍵盤操作已獨立於遊戲快捷鍵。首次完整回歸抓到過廣的焦點攔截影響呼喊，已縮小至配樂區，再跑19項全數通過。

配樂素材共3,715,030 bytes，FFmpeg及Chrome 44.1/48kHz逐曲解碼、峰值、RMS、精確循環及接縫驗證均通過，細節見[soundtrack.md](soundtrack.md)。盤體41個繪製物件、358個重複實例、約33,646個三角形，詳見[stadium-design.md](stadium-design.md)。這些是模型物件數，不是完整場景GPU draw call。

## 界線

本次沒有變更物理、AI、數值、計分、戰績與備份格式；保留目前40–60%勝率及15–40秒平衡回歸，未重跑24,464場完整批次。尚未以實體手機、耳機或喇叭驗證幀率與主觀混音；瀏覽器訊號測試不代表所有硬體聆聽品質。
