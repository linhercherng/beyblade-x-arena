# v0.34.0 摩擦、碰撞與衝刺音效交接

在既有三組材質快取與單顆持續摩擦聲源之外，只增加一個共用摩擦音量節點，不增加聲源或依賴套件。摩擦音保留軸心材質與同一動畫相位，在短暫瞬態下退讓：一般碰撞55%、衝刺命中28%、有齒軌咬合60%、出口加速45%。事件音起音前4ms排入退讓，原事件仍延後8ms開始；碰撞／衝刺較清楚後，摩擦底音平滑回復。

重疊事件維持較深的退讓與較晚恢復時刻，較弱擦碰不會提早取消衝刺音的空間。自然恢復採120ms時間常數；精彩重播按HIGHLIGHT_RATE=0.55延展保持與恢復。原摩擦的音量上限、語音優先增益、配樂音量偏好與限制器保留。

碰撞新增既有軸心材質截止頻率與接觸方向的共同濾色。碰撞與衝刺播放速率、濾波頻寬一起乘慢放倍率，特殊軸心的衝刺脈動與配樂退讓恢復也隨之延長；沿用原音色樣本與既有碰撞／衝刺節流。一般對戰維持1倍。

暫停、靜音、中斷、跳轉或離開盤面沿用既有清理；摩擦退讓狀態也一併清除。恢復採音訊時鐘的指數追蹤，避免無輸入期間的線性尾段在重新接入後殘留衰減。回歸先確認暫停時排程已清，再在恢復有聲後量測增益；另以常數源量測實際輸出，不只依賴AudioParam.value。

## 驗證範圍

新測試先在舊行為觀察到未退讓與重播未降速，再驗證三材質連續交戰、較弱事件不取消較強退讓、摩擦聲源身分維持、音量恢復、碰撞／衝刺聲部上限、0.55倍播放與頻寬、暫停恢復與峰值限制。既有材質、音訊中斷、精彩重播、終結播報、v1～v5舊戰績及平衡報告繼續回歸。

摩擦仍最多雙方各一個聲源；衝刺維持每人一個主聲部與原15ms替換淡出，碰撞保留原5／6聲部上限。沒有修改能力值、物理、隨機種子、戰績格式或舊引擎。

瀏覽器量測及故障注入不代表iPhone／Safari、實體耳機、藍牙與來電硬體驗收。
