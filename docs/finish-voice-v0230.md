# v0.23.0 終結與勝負語音

以開場相同的 Microsoft David Desktop 本機 SAPI 聲線預先製作，強調語氣、輕微提高音高與速度，保留既有金屬／衝擊終結聲。使用 16 kHz 單聲道 PCM，九段共約 9.14 秒，隨程式載入，不依賴裝置語音服務或外部下載。

| 情境 | 播報 | 秒 |
| --- | --- | --- |
| 爆裂 | Burst Finish! | 1.13 |
| 越界 | Over Finish! | 0.97 |
| 極限 | Extreme Finish! | 1.37 |
| 停轉 | Spin Finish! | 1.08 |
| 同時終結 | Draw! | 0.61 |
| 單人獲勝／落敗 | Victory! / Defeat! | 0.68 / 0.62 |
| 雙人贏家 | Player One Wins! / Player Two Wins! | 1.34 / 1.35 |

與倒數共用單一語音聲源，播報時配樂增益降至 0.1、音效降至 0.32，語音直接接入總混音限制器；全句播放後平滑恢復。語音與音效沿用全域靜音，配樂音量偏好不被覆寫。暫停、背景、來電／路由中斷、離開或跳過都清理語音，恢復不補播。

現場每回合播報一次；精彩重播維持慢動作音效，避免再次喊終結。歷史戰績正常播放至終結可播報，拖曳快轉不補播。單人結算依玩家勝負播報；雙人依實際贏家播報。未修改物理、分數、隨機種子、存檔格式或舊版引擎。

驗證包含九段音訊完整播放、單雙人實際結算、配樂／音效壓低與恢復、中斷清理、原開場倒數及發射。Chrome 原生 Web Audio 分析器測得終結語音 RMS 0.106、同時配樂 0.0039、音效 0.0128，混音峰值 0.248。測量為軟體音訊圖，不代表 iPhone 實機聽感或耳機驗收。

核心 120 項通過；倒數／發射與終結語音 11 項通過；正式雙人、路由中斷、終結演出及重播音訊 18 項通過。單人完整對戰初次與核心測試同時執行時遇到音訊中斷自動暫停，獨立重跑完整流程通過（1.3 分鐘）；未關閉或繞過中斷保護。獨立程式審查未發現阻擋發布的問題。完整平衡與公開站結果另由發布 CI 及驗收產物記錄。

初次 CI 的 16 項瀏覽器測試通過，但正常倒數測試因取樣跳過 1 而失敗。既有開場不補播漏掉的階段，因此正常四段播放測試改走選隊、準備發射，再等待競技盤與原生音訊時鐘穩定一秒後鎖定發射；以真實時鐘驗證實際播放與完整結束；另外保留 opening-pause 的長取樣空窗測試，不修改遊戲時間與行為。公開站單雙人完整播報及 v1、v5 匯入重播四項通過，JS／CSS 與本機產物逐位元一致。
